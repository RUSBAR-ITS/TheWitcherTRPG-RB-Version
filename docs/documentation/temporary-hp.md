# Временные ПЗ профессиональной способности

**Принято пользователем 2026-09-20:** [TASK-0012 завершена](../tasks/task-0012-temporary-hp.md#closure), включая доступные настройки всех десяти навыков профессии. Статические и игровые результаты — в [протоколе](../analytics/task-0012-checks.md); прежние датированные отметки об ожидаемой приёмке ниже относятся к истории.

**Обновление .00142:** настройки профессии доступны и при пустых названиях веток; локальные проверки исправления прошли, игровой повтор впереди. Основная игровая приёмка временных ПЗ на .00139 уже выполнена, её границы — в [протоколе](../analytics/task-0012-checks.md#browser-00139).

Общая шестерёнка профессии открывает пять вкладок: «Основной навык», три ветки и «Активные эффекты». Каждая ветка содержит три навыка. До заполнения названия используются подписи «Ветка1–3» и «Навык1–3»; они не записываются как имена в данные. ID в карточке принадлежит именно этому навыку, а не всей профессии. Все десять ID доступны здесь, именование веток их не меняет.

Реализация TASK-0012, 14.3.1.00139. Статические проверки пройдены; игровая приёмка ещё не проведена.

В настройках нужного навыка профессии включите собственное действие и выдачу временных ПЗ. Настройки принадлежат конкретному слоту профессии.

| Настройка | Поведение |
| --- | --- |
| Фиксированное количество | Формула вычисляется один раз; необходимость проверки задаётся галочкой |
| За пункт превышения | Проверка обязательна; полная формула независимо вычисляется за каждый учитываемый пункт, затем результаты складываются |
| Проверка | Характеристика получателя × множитель; результат способности должен быть строго больше сложности |
| Максимум превышения | Ограничивает число учитываемых пунктов в режиме за пункт |
| Округление | Вверх или вниз один раз после сложения всей суммы; по умолчанию вверх |
| Длительность | Отдельная формула, вычисляемая один раз при выдаче |
| Раунды | Отсчитываются по номеру раунда боя получателя; до начала/вступления в бой запас уже доступен, но отсчёт ожидает |
| Минуты, часы, дни | Подпись для ведущего, без автоматического удаления по мировому времени |

Формулы поддерживают арифметику, скобки и кости Foundry. В режиме за пункт при трёх учитываемых пунктах `1d6+2` означает три независимых d6 и суммарно +6. Нулевая или отрицательная настройка не запрещает создание эффекта, но неположительный запас не поглощает урон и не увеличивает его.

## Помощник параметров

«Вставить параметр» возле количества и длительности позволяет выбрать источник или получателя, характеристику/навык и базовое либо действующее значение. В формуле появится `@pN`, под настройками — расшифровка. Ссылки можно повторять; сама формула остаётся редактируемой. Бонусы только к броску, полный избыток за пределами параметра и текущие остатки ресурсов в эти значения не включаются.

Доступны стандартные навыки, текущая способность, произвольные навыки-предметы и навыки других профессий. Для последних используется **идентификатор навыка**, отдельный от UUID предмета. Новый навык/профессия получают ID при создании; копии сохраняют ID того же навыка, включая все слоты профессии. В форме он доступен для просмотра и настройки. Если у ранее созданного навыка поле пустое, кнопка создания ID назначает его явным сохранением; автоматического переписывания старых предметов при открытии листа нет.

Помощник перечисляет навыки текущего персонажа, открытой профессии и каталога предметов мира. Нужный шаблон из компедиума предварительно импортируют в каталог. Ссылка разрешается у выбранного участника по ID; одинаковое название не заменяет ID. Если навыка нет или на участнике найдены два подходящих экземпляра, применение сообщает об ошибке до броска. Неиспользуемые в формулах ссылки не требуют наличия навыка.

## Пример «Рвения»

За пункт превышения; сложность — Интеллект получателя ×3; максимум пять пунктов; количество `1d6`; округление вверх; срок `2*@p1` раундов, где p1 — базовый уровень применяемой способности источника. Суточные ограничения контролирует ведущий. Настройки можно менять для других способностей: код не проверяет их название.

## Получение, расход и окончание

Количество и длительность сохраняются в выданном эффекте и в карточке доставки. Повторная отправка из ожидающей карточки использует уже рассчитанный результат, не перебрасывает кости и не меняет цель. Боевой старт назначается при фактическом создании эффекта у получателя.

Урон обычным ПЗ сначала расходует самый старый активный запас. Частичный расход сохраняет другие изменения эффекта. После исчерпания всех его положительных запасов удаляется весь эффект, включая дополнительные модификаторы. Урон Выносливости временные ПЗ не расходует. Сумма на обоих листах использует тот же список источников.

Выданный в раунде 3 эффект на два раунда снимается при переходе к раунду 5. Пропуск раундов учитывается, повторные события одного раунда не списывают срок повторно. Завершение, удаление или сброс связанного боя снимает его раундовые эффекты; ручные сроки и другие бои остаются отдельно. Перезагрузка страницы не восстанавливает запас и не начинает срок заново. Автоматические записи выполняет активный GM.
