# Архитектурные решения

Согласованные решения перечислены ниже; состояние реализации указывается отдельно.

Новые решения сначала обсуждаются и согласовываются с пользователем, затем добавляются в этот журнал. Предложение или обнаруженная проблема не являются принятым решением.

Для каждой записи указываются:

- ID и дата;
- согласованное решение;
- причина и относящиеся к нему материалы;
- состояние реализации.

Нумерация записей началась с `DEC-0001`; следующий свободный номер — DEC-0002. Правила работы находятся в [разделе rules](../rules/README.md).

## DEC-0001 — Формат и локальный поиск справочника

Дата: 2026-09-14. Пользователь согласовал предложение TASK-0006.001 и поручил продолжить реализацию.

**Решение:** хранить каталог исходников, сущности, отношения и процессы в JSONL в docs/analytics/system-index/; манифест перечисляет части и проверенный срез. Постоянные ID, отдельный охват и динамические/внешние границы определяются [форматом v1](../analytics/system-index/format.md). Поиск и проверка работают локально на Python 3 со стандартной библиотекой, без внешней службы и исполнения игрового кода.

**Причина:** адресуемые краткие записи и ограниченный обход позволяют переходить к нужным участкам подробного аудита. Прямой и обратный поиск используют одни отношения; версии и неполное покрытие остаются явными.

**Реализация:** [TASK-0006.002](../tasks/task-0006.002.md) завершена; [инструмент и инструкция](../analytics/system-index/README.md), [проверки](../analytics/system-index/review-log.md#task-0006002). Начальные данные охватывают три источника частично; наполнение остального справочника продолжается в TASK-0006.
