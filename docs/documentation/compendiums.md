# Компедиумы: текущие модели и инструменты

Состояние исходников: `rusbar-main`, `059f0c7`; дата проверки — 2026-09-10. Источники — модели документов, их регистрация и скрипты этого репозитория.

## Типы содержимого

| Содержимое | Текущий тип документа |
| --- | --- |
| Раса | Item `race` |
| Профессия | Item `profession` |
| Оружие / броня | Item `weapon` / `armor` |
| Алхимический предмет | Item `alchemical` |
| Рецепт / чертёж | Item `diagrams` |
| Критическая травма | Item `criticalWound` |
| Монстр / персонаж | Actor `monster` / `character` |

Типы проверяются по [system.json](../../system.json) и [registerDataModels.js](../../module/setup/registerDataModels.js). Перечень описывает модели, а не план создания новых компедиумов.

## Связь рецепта с результатом

В [DiagramData](../../module/data/item/diagramData.js) есть `associatedItemUuid` — ссылка на результат изготовления, и `resultQuantity` — его количество. Модель также содержит компоненты, сложности, время изготовления и признак `isFormulae`.

`prepareDerivedData` разрешает `associatedItemUuid` в связанный Item. Это подтверждение структуры данных по коду; реальный сценарий изготовления здесь не проверялся.

## Исходники и сборка

| Путь | Назначение |
| --- | --- |
| [packsJson](../../packsJson) | Исходные JSON документов компедиумов |
| `packs` | Результаты сборки; путь исключён из Git текущим `.gitignore` |
| [system.json](../../system.json) | Регистрация packs и их типов |
| [utils/packs.mjs](../../utils/packs.mjs) | Сборка JSON в packs через Foundry CLI |
| [utils/extract.mjs](../../utils/extract.mjs) | Извлечение packs с перезаписью соответствующих JSON |

Команды `npm run build:db` и `npm run extract` записывают данные. Их запуск требует согласованного объёма работ и подходящего назначения результата.

Задачи на изменение или наполнение компедиумов не поставлены. Состав и приоритет будущей работы будут определяться с пользователем.
