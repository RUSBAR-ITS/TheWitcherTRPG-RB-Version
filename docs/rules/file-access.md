# Права файлов и доступ Foundry

## Обязательное правило

**Правами доступа занимается только пользователь.** Агенту запрещено менять права, владельцев и группы файлов или каталогов любым способом: `chmod`, `chown`, `chgrp`, ACL, `umask`, setgid/setuid, а также через установщики или замену файлов ради изменения их прав.

Обычные правки существующего файла сохраняют его метаданные доступа. Создание файла не является поручением отдельно назначать ему права. Не обходить правило копированием или заменой файла с другой моделью доступа.

## Ошибка доступа

Сообщить конкретный путь и полученную ошибку. Не исправлять права самостоятельно и не делать вывод о содержимом непрочитанного файла. Продолжать доступные действия только в пределах уже согласованного перечня.

При использовании другого источника явно указать, что именно было проверено. Чтение исходников данных не подтверждает содержимое недоступной действующей БД.

## Проверка со стороны Foundry

Локальное чтение от пользователя разработчика не доказывает доступ службы Foundry. Для подключаемых модулей и шаблонов проверка согласованной реализации включает загрузку через HTTP и ошибки клиента.

Адрес ресурса определять по фактической регистрации системы и её путям. При ошибке сообщить адрес, статус и связанное сообщение; назначение прав остаётся за пользователем.

Изменение Markdown само по себе не требует запуска мира или изменения настроек службы.
