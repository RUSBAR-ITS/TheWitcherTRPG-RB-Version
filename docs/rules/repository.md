# Git и организация работы

## Ветки

- `rusbar-main` — основная ветка работы над проектом.
- `original` — исходная версия для сравнения и восстановления. Текущие доработки в неё не вносятся.

Перед работой проверить ветку и рабочее дерево. При сравнении указывать конкретный коммит, поскольку имя ветки не фиксирует содержимое навсегда.

Восстановление исходников из Git и восстановление данных миров Foundry — разные операции. Переключение ветки само по себе не возвращает состояние игровых документов.

## Согласование изменений

До изменения файлов, создания или удаления веток, коммитов и публикации агент описывает предлагаемое действие и получает согласие пользователя. Выполняется согласованный перечень; новые решения и расширение объёма сначала обсуждаются.

Сохранять незакоммиченные изменения, не относящиеся к поручению. Не использовать сброс или очистку для удаления чужой работы. Сообщение коммита должно соответствовать фактически выполненным изменениям.

## Доступ

Права, владельцы и группы регулируются [file-access.md](file-access.md). Согласование изменения содержимого файла не является поручением изменить его права.
