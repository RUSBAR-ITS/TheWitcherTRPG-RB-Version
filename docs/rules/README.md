# Правила работы с репозиторием

**Любые изменения и новые решения предварительно согласовываются с пользователем.** Агент сначала описывает конкретный перечень предлагаемых изменений, получает согласие и затем выполняет одобренную работу. Дополнения к перечню требуют отдельного согласования.

| [development.md](development.md) | Согласование, исследование и реализация |
| [testing.md](testing.md) | Проверки и достоверность результатов |
| [documentation.md](documentation.md) | Документы, проблемы, задачи и журнал решений |
| [issues.md](issues.md) | Регистрация, подтверждение и закрытие проблем |
| [file-access.md](file-access.md) | Права, владельцы, группы и ошибки доступа |
