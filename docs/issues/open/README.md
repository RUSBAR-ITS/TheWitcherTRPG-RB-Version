# Открытые проблемы

В этом каталоге находятся проблемы, которые пользователь подтвердил и которые необходимо исправить. Конкретные изменения согласовываются до выполнения; статус `open` не является разрешением изменять код.

После исправления в карточке записываются результат и проверки. До подтверждения пользователем закрытия карточка остаётся здесь. После подтверждения она перемещается в `closed` с сохранением имени и ID.

Список карточек ведётся в [общем реестре](../README.md). Порядок работы — в [правилах](../../rules/issues.md), состав документа — в [шаблоне](../templates/issue.md).
