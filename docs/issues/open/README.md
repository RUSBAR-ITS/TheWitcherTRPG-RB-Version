# Открытые проблемы

В этом каталоге находятся проблемы, которые пользователь подтвердил и которые необходимо исправить. Конкретные изменения согласовываются до выполнения; статус `open` не является разрешением изменять код.

После исправления в карточке записываются результат и проверки. До подтверждения пользователем закрытия карточка остаётся здесь. После подтверждения она перемещается в `closed` с сохранением имени и ID.

Список карточек ведётся в [общем реестре](../README.md). Порядок работы — в [правилах](../../rules/issues.md), состав документа — в [шаблоне](../templates/issue.md).

[issue-00001](issue-00001.md) — подтверждена пользователем 2026-09-16; реализовано согласование ID пакета, ресурсов и зависимых технических пространств имён. Проверки и остаток живой приёмки описаны в карточке; закрытие не подтверждено.

[issue-00330](issue-00330.md) — общая проблема локализации ru/en и терминологии рулбуков, создана в open по поручению пользователя 2026-09-16. Содержит текстовые исправления по 20 исходным карточкам, изменения документации и рекомендации по проверкам. По уточнению пользователя механики и обработка данных исключены; смежные карточки приведены только для разграничения. issue-00326 и компедиумы также исключены и предназначены для отдельной задачи. «СЛ собирания» сохраняется по решению пользователя; реализация не начата.
