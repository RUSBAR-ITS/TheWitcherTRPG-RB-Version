## Общее описание проблемы

В настройках новой профессии через общую шестерёнку видны только общая вкладка и активные эффекты. Три вкладки дополнительных веток получают пустые подписи из `pathName` и фактически недоступны для клика. Подпись общей вкладки не объясняет, что показанный ID относится к основному навыку. Узкие карточки формы разбивают подписи на множество строк.

## На что влияет в системе

Настройка девяти дополнительных навыков, их идентификаторов, атак/защит, порогов и временных ПЗ через графический интерфейс. Данные десяти навыков существуют: это ошибка доступа и представления, а не отсутствие ID или девяти слотов в модели.

## Почему это проблема

Настройки должны быть доступны сразу после создания профессии, независимо от заполнения названий. Назначение поля ID должно быть однозначным. Расширение окна сейчас не устраняет ограничение ширины карточки.

## Где конкретно локализована в коде

- [WitcherProfessionConfigurationSheet._prepareTabs](../../../module/item/sheets/configurations/WitcherProfessionConfigurationSheet.js): присваивает `skillPath1–3.pathName` без резервных подписей.
- [general.hbs](../../../templates/sheets/item/configuration/tabs/general.hbs): общая вкладка содержит `definingSkill`; это ID основного навыка.
- [skillPathPart.hbs](../../../templates/sheets/item/configuration/partials/profession/skillPathPart.hbs) и [skillPathSkillPart.hbs](../../../templates/sheets/item/configuration/partials/profession/skillPathSkillPart.hbs): три карточки навыков на ветку, заголовки только из `skillName`.
- [profession-sheet.css](../../../styles/profession-sheet.css): общий `.profession-card` ограничен 400 px. [Базовое окно](../../../module/item/sheets/configurations/WitcherConfigurationSheet.js) — 520×480 px.
- [skillIdentity.js](../../../module/item/skillIdentity.js): создание десяти skillId уже реализовано, пересоздание идентификаторов для этого исправления не требуется.

## Предложение по изменению

[Проект .009](../../tasks/task-0012-temporary-hp.md#task-0012009): резервные названия трёх вкладок, явная подпись основного навыка и карточек, подсказка назначения ID, отдельный размер/стили редактора профессии и прокрутка. Новые подписи через ru/en; имена и ID в данных не заполнять и не менять при render. Подробные файлы и локальная/браузерная приёмка находятся в задаче.

## Воспроизведение и доказательства

Создать профессию с пустыми названиями, открыть шестерёнку. В реальном редакторе найдены десять непустых `input[name$=".skillId"]`. Три ссылки вкладок веток имели пустой текст и размер 10×0 px; попытка клика завершилась ожиданием невидимого элемента. Размер окна — 520×480, карточки — 400×288; подпись ID — около 131×64 px. Чтение/рендер не меняли пользовательский Item.
