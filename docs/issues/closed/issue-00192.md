## Уточнение плана 2026-09-18 — .00057

Принято пользователем: **для монстров только ручное редактирование** навыков/параметров. Не добавлять монстрам модель ОУ, журнал покупок или автоматическое развитие персонажа. Кнопки покупки уровня для них не предлагать; прямой вызов обработчика также не должен запускать списание или обращаться к отсутствующим logs/magic. Ручные поля сохраняются. План — [TASK-0010.006](../../tasks/task-0010-parameter-limits.md#task-0010006). Код ещё не исправлен.

## Общее описание проблемы

Текущий WitcherMonsterSheet открывает общую WitcherModifiersConfiguration для группы skills. edit-skills создаёт level-up кнопки и общий listener вызывает Actor.levelUpSkill, требующий logs/magic/IP персонажа, которых нет в MonsterData.

## На что влияет в системе

Повышение навыка из текущего редактора монстра. См. также [issue-00030](../potential/issue-00030.md) о ранее зарегистрированной общей IP-вкладке. Эта карточка выделяет другое действие — автоматическое повышение в отдельном редакторе. Общая вкладка дополнительно содержит поля IP/training и ссылки, обработчики которых найдены только в CharacterSheet; их сохранение в мире здесь не проверено.

## Почему это проблема

Действующий интерфейс предлагает операцию, предусловия которой его модель не выполняет. Прямой вызов по ключу обычного или магического навыка завершается TypeError вместо осмысленного изменения/отказа.

Оболочки Application/Actor и события контролируемые; browser click/сохранение общей IP-вкладки не исполнялись.
