# Закрытые проблемы

В этом каталоге находятся проблемы, закрытие которых подтверждено пользователем. В каждой карточке должны быть указаны основание закрытия, результаты выполненных проверок и решение пользователя.

Закрытие возможно после исправления или по другой подтверждённой причине, например если наблюдение не является ошибкой или дублирует другую карточку. Само по себе успешное выполнение проверки агентом не разрешает перенос в `closed`.

Список карточек ведётся в [общем реестре](../README.md). Порядок работы — в [правилах](../../rules/issues.md), состав документа — в [шаблоне](../templates/issue.md).
