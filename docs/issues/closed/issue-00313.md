## Общее описание проблемы

utils/extract.mjs удаляет все найденные корневые JSON в packsJson/<pack> до вызова extractPack. Если удаление либо извлечение завершается ошибкой, прежние исходники остаются частично или полностью удалёнными; собственного восстановления нет.

## На что влияет в системе

Рабочие JSON-исходники компедиума при npm run extract; в том числе незакоммиченные правки. Не утверждается, что какие-либо реальные файлы пользователя были потеряны.

## Почему это проблема

Отказ чтения/экспорта базы становится причиной потери предыдущего набора исходников. CLI сам извлекает во временную папку и копирует результат позднее, но предварительное удаление в системном скрипте происходит раньше этой границы.
