## Общее описание проблемы

Локализация ru/en неполна и местами расходится с ключами, действиями интерфейса и терминологией предоставленных книг. Первоначальная матрица охватывает текстовую часть 20 локализационных карточек; по повторному поручению пользователя добавлены восемь групп оставшихся действий N01–N08 ниже. Исправление компедиумов, включая имена эффектов, исключено по указанию пользователя. Три смежные проблемы обработки данных исключены из плана по указанию пользователя. Дополнительно включает проверку потенциально лишних записей и терминологические исправления.

В первоначальном объёме 20 исходных карточек. Дополнительные действия повторной проверки перечислены отдельно, без создания новых issues. По поручению пользователя все 20 решённых исходных карточек перенесены в closed; issue-00178 закрыта после устранения остатка в 14.3.1.00010. Исключённые карточки сохраняют свои статусы. ID и история доказательств сохранены; частичное исправление подписи не означает исправления всей исходной проблемы.

Целевые языки — только ru и en. Компедиумы, packsJson, packs и их сборка не входят в работу; для исправления компедиумов пользователь предусмотрел отдельную задачу. Сохраняемые технические значения, схемы данных и миграции в этой работе не меняются. Пользовательские имена и старые сообщения чата массово не переводятся.

## На что влияет в системе

Подписи параметров/навыков, настройки персонажей и чудовищ, ActiveEffect, инвентарь/вес, рецепты, профессии, магия/регионы, награды, испытания, расследования и названия источников штрафов травм. В диалогах словесной защиты исправляются только переводы существующих подписей.

Различать: технический ключ вместо текста; английский fallback в ru; английскую строку вне localize; неверный перевод; правильный перевод чужого действия; потерянный label до локализатора. Исправление только JSON не устраняет все причины.

## Почему это проблема

Интерфейс должен использовать понятия рулбуков: Устойчивость не равна оглушению, Улика не равна подсказке, состояние после лечения не означает полное заживление. Английский fallback маскирует пробелы ru, поэтому отсутствия ошибок в консоли недостаточно.

**Граница работы: только отображаемый текст и обращения к локализации.** Допустимы переводы, ключи localize/format/label/hint и сопоставление существующего технического значения с подписью. Формулы, числа, условия, результаты бросков, способы подготовки моделей, события, сохраняемые enum/IDs и обработка данных остаются прежними. Если исправление требует изменения механики или рефакторинга модели/обработчика, оно исключается из этой issue и обсуждается отдельно. Рулбуки здесь служат источником терминологии, а не основанием менять правила системы.

## Предложение по изменению

2026-09-16 пользователь подтвердил завершение перевода и прямо поручил закрыть задачи: «Так с переводом кажется закончили можешь закрывать задачи». На этом основании общая issue-00330 перенесена в closed. Все 20 исходных локализационных карточек уже закрыты; дополнительных задач TASK для этой реализации не создавалось.

Согласованный объём выполнен: первоначальные исправления T01–T29 и пропуски ru, затем N01–N08, включая подписи всех 13 типов рецептов и замену «диаграмм» на согласованные термины. Прежние ключи локализации сохранены. Выполненные проверки реализации описаны выше: для N01–N08 — 44 адресных сценария ru/en, 78 рендеров атрибутов, компиляция 22 HBS, синтаксис четырёх JS и сверка 28 HTTP-ресурсов. Закрытие опирается на эти результаты и подтверждение пользователя; собственная живая браузерная проверка агентом и проверка установленного Polyglot не заявляются.

Отложенные ошибки пустой шапки персонажа и пустого типа рецепта, смежные механические проблемы и [issue-00326](../potential/issue-00326.md) по компедиумам этим закрытием не объявляются исправленными. Их описание и ранее установленные границы сохранены.
