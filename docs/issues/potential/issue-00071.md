## Общее описание проблемы

В skillDefense есть boolean isDefense, который UI использует для показа полей. ProfessionData.isApplicableDefenseInPath и findDefensePathData обращаются напрямую к defendsAgainst, не проверяя флаг.

## На что влияет в системе

Защитный навык в одной из веток профессии может оставаться доступным после выключения isDefense, если сохранён defendsAgainst.

## Почему это проблема

Выключение конфигурационного флага не исключает способность из общего списка защит. Модель сохраняет настройки при отключении, поэтому отбор должен отдельно учитывать флаг, если он предназначен именно для включения защиты.
