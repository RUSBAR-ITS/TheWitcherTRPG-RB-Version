## Общее описание проблемы

CriticalWoundData.treat ожидает только fromUuid. Затем запускает createEmbeddedDocuments и сразу delete исходного Item, не проверяя результат создания. При недоступном UUID в создание передаётся [null]; отказ создания не удерживает удаление.

## На что влияет в системе

Ручное лечение с листа Actor и завершение заживления через отдых. При неудачной замене возможно исчезновение исходной травмы без созданной следующей; потеря игрового документа в действующем мире не воспроизводилась.

## Почему это проблема

Для перехода по непустому followUp удаление исходной записи предполагает успешное создание получателя. Текущая последовательность этого не обеспечивает. Пустой followUp — отдельно предусмотренная ветвь полного удаления, она не является предметом этого наблюдения.

## Предложение по изменению

После отдельного согласования проверять владельца и разрешённый документ; дожидаться создания и проверять непустой результат до удаления исходной травмы. Отдельно определить действия при недоступной ссылке, отмене hook и циклическом followUp. Решение и исправление не согласованы.

## Воспроизведение и доказательства

Выполнен настоящий treat. Для существующего followUp зарегистрированы create,delete, а метод уже завершён, пока оба Promise остаются pending. Для fromUuid→null зарегистрированы create('Item',[null]) и delete; последующий rejection Promise создания не отменил delete. Контроль: rejection самого fromUuid остановил метод до удаления; при Item без Actor и непустой ссылке получен TypeError createEmbeddedDocuments, delete не вызван. Common DataModel.cleanData и ClientDatabaseBackend проверены по исходникам: Document/DataModel допускается, null — нет. Поэтому сам факт передачи настоящего Item вместо toObject не объявлен ошибкой.

Ожидаемое поведение обосновано выше отдельно от фактического результата. Сценарии, версии, подмены и общие ограничения — в [журнале сверки](../../analytics/code-audit/review-log.md#task-0003020). Операции записи перехватывались; эти результаты не подтверждают состояние действующего мира.
