## Общее описание проблемы

customSkillMixin добавляет/редактирует/удаляет system.modifiers, которого нет в SkillItemData. Добавление создаёт name/value без id, хотя edit/remove ищут id. Удаление неизвестного id использует splice(-1,1). В текущих templates кнопок этих трёх операций не найдено.

## На что влияет в системе

Вызываемые методы старого CRUD собственных модификаторов и возможность сохранения ожидаемой ими структуры. Не утверждается, что пользователь сейчас может воспроизвести все операции кнопками действующего листа.

## Почему это проблема

Методы не имеют устойчивого контракта с моделью и собственным созданием строк: модель отбрасывает массив, а адресация операций требует не создаваемый ID. Для явно внедрённого массива неизвестный ID удаляет другую строку вместо отказа.

## Предложение по изменению

Сначала согласовать, нужен ли старый массив в целевой модели. При сохранении механизма согласовать схему, устойчивые ID и обработку отсутствующих строк вместе с интерфейсом. Не добавлялись ни поля, ни кнопки, ни проверки.

## Воспроизведение и доказательства

Настоящая SkillItemData при создании и updateSource не сохраняет modifiers. Реальный add-handler выдал [{name:'Modifier', value:0}], без id. В отдельном сценарии массив внедрён в обход модели: remove с несуществующим id удалил последнюю строку; без массива получен TypeError; edit записал строку '-3', а неизвестный id вызвал TypeError. Эти вызовы изолированы; Item.update перехвачен, отсутствие действующих кнопок явно проверено поиском всех templates.
