## Общее описание проблемы

Оба обработчика запросов возвращают true после вызова целевой функции, не ожидая её Promise. В ветке методов query вернёт true даже при отсутствии метода на entity и entity.system.

## На что влияет в системе

Подтверждение удалённых операций добавления предмета, улучшения и применения эффектов; передача ошибок вызывающему клиенту.

## Почему это проблема

Успешный ответ может прийти до окончания диалога или записи документа. Ошибка асинхронной операции не связывается с Promise обработчика; отсутствие метода также не отличается от выполненной операции.

## Где конкретно локализована в коде

- [module/setup/queries.js](../../../module/setup/queries.js) — applyTemporaryItemImprovementsToActor, строки 9–12; query, строки 34–43.
- [module/actor/mixins/temporaryEffectMixin.js](../../../module/actor/mixins/temporaryEffectMixin.js) — applyTemporaryItemImprovements ожидает DialogV2.prompt и шаблон сообщения.
- [module/actor/witcherActor.js](../../../module/actor/witcherActor.js) — addItem, строка 259: ожидает update/createEmbeddedDocuments.

## Предложение по изменению

Согласовать контракт ответа (принятие запроса или завершение операции), проверять существование единственной целевой функции и связать её результат/ошибку с ответом согласно выбранному контракту. Для таблицы разрешённых функций учитывать только собственные ключи. Конкретное исправление не согласовано.

## Воспроизведение и доказательства

В исходный query из Node vm передан addItem с управляемым незавершённым Promise: await query вернул true при complete=false; после ручного разрешения операции complete=true. Такой же результат у специального запроса улучшений. Объект без методов на двух проверяемых уровнях также дал true. Дополнительно function='constructor' принят через оператор in у обычного объекта; неизвестное имя вернуло false.

Пределы проверки: Целевые операции в опыте заменены управляемыми заглушками, реальные документы не создавались. В Foundry User.query возвращает ответ обработчика (локальный /opt/foundryvtt/client/documents/user.mjs:283–321); межклиентская доставка не воспроизводилась. Перехват позднего rejection не запускался, его потеря следует из отсутствия await/return.
