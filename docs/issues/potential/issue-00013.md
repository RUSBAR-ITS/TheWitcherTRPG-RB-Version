## Общее описание проблемы

MonsterData.enrichedText создаёт для common, academicKnowledge и monsterLore тройку value/enriched/systemField. Шаблон monster-knowledge.hbs передаёт `.value` в параметр `enriched` всех трёх formGroup, хотя подготовленный HTML находится в `.enriched`.

## На что влияет в системе

Изолированный рендер исходного HBS подтвердил неверный аргумент во всех трёх полях знаний монстра. Возможное проявление — отображение необработанных UUID-ссылок и другой разметки в свёрнутом редакторе. Работа настоящего браузерного редактора и разрешение реальных ссылок не проверялись.

## Почему это проблема

Контракт помощника явно разделяет исходное значение для редактирования и обработанный HTML для показа. Элемент prose-mirror в Foundry использует параметр enriched при отображении выключенного редактора. Передача value теряет подготовленный результат модели.

## Предложение по изменению

При согласовании исправления передавать `.enriched` в параметр enriched, сохранив исходное значение для value. Проверить все три редактора в браузере на обычном тексте и документной ссылке. Предложение не реализовано и не согласовано.

## Воспроизведение и доказательства

1. Задать три поля знаний непустым текстом, например `<p>@UUID[Actor.example]</p>`.
2. Получить результат исходной MonsterData.enrichedText с различимым результатом обогащения.
3. Скомпилировать и отрендерить исходный monster-knowledge.hbs, перехватив hash.enriched в formGroup.
4. Сравнить переданные параметры с lore.<поле>.enriched и lore.<поле>.value.

**Фактический результат:** В трёх вызовах hash.enriched равен исходному value и отличается от подготовленного enriched.

Использованы реальная MonsterData и исходный шаблон, Handlebars 4.7.9 из установки Foundry. TextEditor.enrichHTML возвращал отличимый маркер; formGroup перехватывал аргументы, localize возвращал ключ. Модель создала обработанный текст, но шаблон передал исходный. Поведение prose-mirror дополнительно сверено чтением `/opt/foundryvtt/client/applications/elements/prosemirror-editor.mjs`:36–45, 165, 372–390.

**Пределы проверки:** Фактический HTML-редактор, DOM и ссылки Foundry не воспроизводились. Выполнена проверка передачи данных шаблоном, не пользовательского вида страницы.

Команды и результаты находятся в [сверке TASK-0003.001](../../analytics/code-audit/review-log.md#task-0003001). Повторная проверка не пишет в игровые документы.
