## Общее описание проблемы

У двух флагов боковой панели персонажа отсутствуют русские значения четырёх ключей: WITCHER.Actor.woundThreshold.ignore, WITCHER.Actor.woundThreshold.ignoreHint, WITCHER.Actor.deathState.ignore, WITCHER.Actor.deathState.ignoreHint.

## На что влияет в системе

Подписи и подсказки галочек игнорирования порога ранений и состояния при смерти в русской локализации.

## Почему это проблема

Английские значения существуют, и штатный fallback возвращает их, поэтому часть русскоязычного интерфейса остаётся английской. Работу самих галочек это наблюдение не оспаривает.

## Где конкретно локализована в коде

| Файл | Локализация |
| --- | --- |
| [templates/sheets/actor/partials/character/sidebar.hbs](../../../templates/sheets/actor/partials/character/sidebar.hbs) | Четыре localize для flags.healthState.woundThreshold/deathState.ignored:107,110,120,123 |
| [lang/ru.json](../../../lang/ru.json) | Отсутствуют четыре значения после expandObject |
| [lang/en.json](../../../lang/en.json) | Английские значения ключей присутствуют |

## Предложение по изменению

Согласовать русский текст для двух подписей и двух подсказок, затем добавить переводы. Код и словари не менялись.

## Воспроизведение и доказательства

Группа 26: проверены реальные словари после foundry.utils.expandObject и настоящий Localization.localize Foundry 14.367.0 с ru translations/en fallback. В трёх файлах порции обнаружены 52 строки WITCHER.: 49 полных ключей и три префикса (Actor.tabs, Homelands., socialStanding.). Все 49 полных ключей есть в en; только указанные четыре отсутствуют в ru. Префиксы не посчитаны отсутствующими переводами. Это отдельное наблюдение; корректировка прежней языковой части issue-00193 сохраняется. Дополнительные модули локализации и другие языки не исследовались.
