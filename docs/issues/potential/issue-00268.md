## Общее описание проблемы

prepareAndExecuteDefense задаёт action=option.value; Item wrapper использует имя предмета, профессия — имя навыка. DialogV2 сворачивает buttons по action, сохраняя последнюю запись.

## На что влияет в системе

Выбор между одинаково названными предметами/навыками с разными модификаторами.

## Почему это проблема

Разные доступные варианты теряются из интерфейса из-за совпадения отображаемого имени, хотя вход содержит обе записи.
