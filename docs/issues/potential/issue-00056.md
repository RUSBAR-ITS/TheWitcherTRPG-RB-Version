## Общее описание проблемы

Общий effect-part.hbs выводит кликабельный .effect-display и скрытое .effect-description.invisible. Actor-листы подключают раскрывающий listener, Item-конфигурация, использующая тот же partial, такого обработчика не регистрирует.

## На что влияет в системе

Чтение описания эффекта из списка настроек предмета. Открытие отдельного листа эффекта через edit — другой маршрут.

## Почему это проблема

Ссылка отображается вместе со скрытым текстом, но найденные обработчики Item обслуживают только create/toggle/edit/delete. Предполагаемое одинаковое действие раскрытия требует подтверждения пользователя.

## Предложение по изменению

Согласовать подключение раскрытия в Item-конфигурации либо изменение отображения этой строки. Переиспользование обработки и поведение UI выбрать до реализации.

## Воспроизведение и доказательства

Исходный partial с непустым description отрендерен Handlebars: присутствует ссылка .effect-display и скрытый блок invisible. Поиск по module/item/sheets не нашёл listener/action для раскрытия; WitcherConfigurationSheet регистрирует четыре других действия. Исходный Actor-listener отдельно зарегистрировал click для .effect-display, а его метод переключил invisible в jQuery-double.

**Пределы проверки:** На стороне Item выполнены статический поиск и рендер разметки, а не реальный клик в браузере. Внешние модули, которые могли бы добавлять такой listener, не обследовались.
