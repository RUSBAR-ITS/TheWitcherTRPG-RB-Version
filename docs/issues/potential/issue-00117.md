## Общее описание проблемы

Имя навыка вставляется внутрь строки JSON вручную, без экранирования. Имя Aid "quoted" создаёт некорректное value изменения временного здоровья.

## На что влияет в системе

Данные эффекта временных HP и дальнейшие потребители JSON, включая расход временного здоровья.

## Почему это проблема

StringField допускает кавычку, но JSON должен экранировать её. Формирование payload само нарушает требуемый формат независимо от результата броска.

## Предложение по изменению

После согласования сериализовать объект штатным JSON.stringify. Отдельно проверить допустимость имени как сегмента change.key и связь повторных применений, не считать исправление JSON решением всех вопросов идентичности. Решение не согласовано, код не исправлялся.

## Воспроизведение и доказательства

Настоящая ветвь doProfessionSkillUsage с именем Aid "quoted" подготовила value={"name": "Aid "quoted"", "value": 7}; JSON.parse дал SyntaxError. Контрольное имя Aid дало объект {name:'Aid',value:7}, принятый настоящей TemporaryEffects. Эффект и query перехвачены, весь pipeline применения/расхода не запускался.

Использован исходный код указанной версии. Внутри проверки модели Foundry и системные методы настоящие; UI/Actor/запись/бросок/эффект/query подменены только там, где это оговорено сценарием. Методика, результаты и границы приведены в [журнале сверки](../../analytics/code-audit/review-log.md#task-0003019).

Проверка не подтверждает работу или отказ всего процесса в клиенте. Наблюдение не заменяет подтверждения пользователем.
