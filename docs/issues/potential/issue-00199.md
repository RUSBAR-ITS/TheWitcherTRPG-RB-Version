## Общее описание проблемы

Текущий WitcherMonsterSheet использует общий tab-stats с totalStats, но не вычисляет это поле контекста. calc_total_stats вызывается только WitcherCharacterSheet.

## На что влияет в системе

Подпись общей суммы характеристик текущего листа монстра.

## Почему это проблема

Общая вкладка выводит заголовок суммы без числового результата, хотя сами характеристики доступны и общий helper может их суммировать.

| [module/actor/sheets/WitcherCharacterSheet.js](../../../module/actor/sheets/WitcherCharacterSheet.js) | _prepareCharacterData:168 — существующий producer для персонажа |
| [module/actor/sheets/mixins/statMixin.js](../../../module/actor/sheets/mixins/statMixin.js) | calc_total_stats |

## Предложение по изменению

Согласовать, нужна ли сумма монстру. Затем либо готовить контекст, либо условно выводить блок. Вариант не выбран, код не изменён.

## Воспроизведение и доказательства

Группа 19: настоящий _prepareCharacterData Monster, настоящая MonsterData и Handlebars tab-stats. При девяти max8 totalStats отсутствует, получен текст 'Total Stats:' без числа; прямой calc_total_stats для того же контекста даёт 72. Поиск всех module не нашёл другого producer totalStats для монстра. Базовая Application-оболочка заменена; живой браузер не проверялся.
