## Общее описание проблемы

countdownDurationOfRegions выбирает game.scenes.active вместо combat.scene. Таймер deleteSpellVisualEffect использует canvas.scene в момент срабатывания вместо region.parent.

## На что влияет в системе

Длительность и удаление областей при разных сценах боя, просмотре другой сцены или смене сцены до таймера.

## Почему это проблема

ID embedded Region локален сцене. Работа с посторонней сценой пропускает исходный регион; при совпадении ID может адресовать другой документ. Такой риск следует из адресации, но удаление чужого документа в мире не воспроизводилось.

## Предложение по изменению

После согласования привязать операции к документу/сцене региона и правилам сцены Combat; определить поведение при удалённом регионе/сцене и нескольких сценах. Исправление не согласовано и не выполнялось.

## Воспроизведение и доказательства

Группы 14/18: таймер запланирован для региона сцены A, после смены canvas на B вызвал deleteB. Combat связан с A, active=B: отсчёт изменил регион B, A не изменился. При canvas=null callback дал TypeError.

[Методика и результаты сверки](../../analytics/code-audit/review-log.md#task-0003022). Ожидание основано на контрактах кода, без утверждения о правилах книг.

**Пределы проверки:** Таймер вызван вручную, Scene API заменён сборщиками; реальных удалений/переключений не было.
