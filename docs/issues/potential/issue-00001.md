## Общее описание проблемы

Имя каталога checkout — TheWitcherTRPG-RB-Version, а id манифеста — TheWitcherTRPG. В установленном Foundry 14.367.0 серверный fromManifestPath явно сравнивает id с basename каталога и возвращает null при несовпадении. Изолированное исполнение настоящего метода с текущим путём и реальным JSON воспроизвело этот отказ до конструктора System.

Это подтверждённая техническая граница выбранного метода. Сканирование пакетов работающей службой, её список систем, журналы и загрузка мира в этой проверке не выполнялись; фактическое состояние запущенного экземпляра не установлено.

## На что влияет в системе

При передаче текущего пути штатному fromManifestPath пакет не создаётся; вызывающий getPackages включает в коллекцию только ненулевые результаты. Следовательно, в этом маршруте выполнение module/TheWitcherTRPG.js, init/ready и доступность объявленных компонентов не наступают.

Это вывод из прочитанного загрузчика и изолированного метода, а не наблюдение работающего сервера. Конфликт двух уже загруженных систем с одинаковым ID не воспроизводился и не требуется для этого отказа.

## Почему это проблема

Несовпадение нарушает явное предусловие серверного загрузчика Foundry 14.367.0. Причина уже не основана только на сравнении двух строк: конкретный метод возвращает null с ошибкой «Invalid system» для фактического имени каталога.

Проверка была проведена на уровне входа манифеста. Положительный контроль с согласованным именем каталога проходит только эту границу и не доказывает полную валидность пакета, его установку или работу ресурсов.

## Где конкретно локализована в коде

- [system.json](../../../system.json), строка 2: id=TheWitcherTRPG.
- Каталог checkout: /var/lib/foundryvtt/Data/systems/TheWitcherTRPG-RB-Version.
- Локальное ядро /opt/foundryvtt/dist/packages/package.mjs: ServerPackageMixin, методы getPackages, fromManifestPath и loadLocalManifest. Минифицированный файл; fromManifestPath начинается с байтового смещения 4266, фрагмент до следующего static loadLocalManifest — 1563 символа. SHA-256 файла: e77779bc83a740e7e9fa0903d5c83d4f5e5a7ef9112e552d1de9bfd40ea259ec.
- /opt/foundryvtt/dist/packages/system.mjs: System наследует ServerPackageMixin; собственный обход, отменяющий эту проверку, не найден.

getPackages получает каталоги через storage.getDirectories, передаёт manifestPath в fromManifestPath и добавляет только ненулевой результат. Реальный loadLocalManifest читает JSON и сохраняет путь; изолированный фасад воспроизводил именно эти входные данные.
