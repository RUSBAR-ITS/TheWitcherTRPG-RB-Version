## Общее описание проблемы

styles/attack-sheet.css задаёт word-wrap:break-all. У word-wrap, alias overflow-wrap, такого значения нет.

## На что влияет в системе

Правило переноса содержимого ячеек верхних таблиц оружейного и профессионального диалогов. Конкретный визуальный дефект не воспроизведён.

## Почему это проблема

Декларация не соответствует грамматике свойства и не может задавать написанное поведение как валидное CSS-правило. Различие между этой ошибкой и фактическим переполнением UI сохранено.

## Воспроизведение и доказательства

Прочитана declaration, прослежены @import и оба потребителя. Группа 28 сверила строку CSS и DOM-класс. По W3C CSS Text Level3 §5.4 (2026-08-14) overflow-wrap допускает normal, break-word, anywhere, word-wrap — legacy alias; break-all относится к word-break. Ожидание — валидная декларация выбранного свойства.

Источник: [W3C CSS Text Level3](https://www.w3.org/TR/2026/CRD-css-text-3-20260814/#overflow-wrap-property). Браузерный CSS-парсер, computedStyle и скриншоты не проверялись. Широкий h2 img описан в карточке CSS, отдельным дефектом не объявлялся.

[Методика, фиксированные входы и результаты](../../analytics/code-audit/review-log.md#task-0003041). Запуск использовал исходные функции и настоящие модели/Handlebars/Roll; Actor, Dialog, DOM-форма, запись и доставляемые сообщения — фасады. Не все группы исполняют extendedRoll целиком: формулы захвачены на его границе, один отдельный проход использует настоящий helper. Для CSS проверялись исходники и спецификация.
