## Общее описание проблемы

Отправитель addBehaviorsToRegionUuids передаёт UUID Item, но метод находится в item.system.regionProperties, а query проверяет только Item и Item.system. Вторая операция deleteSpellVisualEffect отсутствует в списке query, а при её отправке используется необъявленная переменная item.

## На что влияет в системе

Назначение поведений регионам и удаление визуальных регионов заклинания при действиях игрока через GM.

## Почему это проблема

В одном пути запрос возвращает true без вызова вложенного метода; в другом ReferenceError возникает до отправки, а даже корректно сформированный запрос отвергается маршрутизатором.

## Где конкретно локализована в коде

- [module/setup/queries.js](../../../module/setup/queries.js) — callableEntityFunctions и строки 39–43: два уровня поиска, нет deleteSpellVisualEffect.
- [module/data/item/templates/regions/regionPropertiesData.js](../../../module/data/item/templates/regions/regionPropertiesData.js) — addBehaviorsToRegionUuids и addBehaviorsToRegions, строки 12–23: метод вложенной модели, UUID родительского Item.
- [module/data/item/spellData.js](../../../module/data/item/spellData.js) — regionProperties: EmbeddedDataField(RegionProperties), строка 36.
- [module/data/item/ritualData.js](../../../module/data/item/ritualData.js) — regionProperties: EmbeddedDataField(RegionProperties), строка 33.
- [module/data/item/mixin/spellRegionMixin.js](../../../module/data/item/mixin/spellRegionMixin.js) — deleteSpellVisualEffect, строки 159–167: uuid: item.uuid без определения item.

## Предложение по изменению

Согласовать адресацию разрешённых операций моделей Item, затем привести отправителей и обработчик к одному контракту и проверить оба сценария между игроком и GM. Конкретное исправление не согласовано.

## Воспроизведение и доказательства

Исходный query с объектом system.regionProperties.addBehaviorsToRegionUuids вернул true, счётчик вызовов остался нулевым; function=deleteSpellVisualEffect вернул false. Исходный spellRegionMixin.deleteSpellVisualEffect вызван при isGM=false с минимальным game: ReferenceError: item is not defined. Поиск определения addBehaviorsToRegionUuids в module подтвердил вложенную модель.

Пределы проверки: Не воспроизводились canvas, создание регионов и два клиента; модель в опыте маршрутизации заменена объектом той же формы. Отдельные локальные проблемы сведены здесь в один нарушенный обмен операциями регионов.
