## Общее описание проблемы

damageFormula добавляет meleeBonus лишь для character либо monster.addMeleeBonus=true; передаваемый в HBS meleeBonus проверяет только skillAttack.applyMeleeBonus.

## На что влияет в системе

Предпросмотр профессиональной атаки у монстра с отключённым addMeleeBonus.

## Почему это проблема

Отдельная ячейка сообщает бонус, которого нет в показанной и реально переданной формуле урона.
