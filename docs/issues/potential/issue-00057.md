## Общее описание проблемы

Тип note объявлен в манифесте и имеет NoteData, но не получает специализированного листа. Общий WitcherItemSheet зарегистрирован без ограничения types и задаёт PARTS={}; лежащий в templates/sheets/item/note-sheet.hbs шаблон не подключён к этому листу.

## На что влияет в системе

Редактирование имени и описания Item типа note через основной лист: в проверенном маршруте не создаются части формы.

## Почему это проблема

Существуют тип, модель и отдельный шаблон заметки, однако регистрация и рендер не связывают их. Ожидание доступного редактора следует из этих определений; фактический вид окна в браузере ещё не проверен.

## Предложение по изменению

Согласовать подключение редактора note к зарегистрированному листу и проверить форму на ApplicationV2. Не назначать старый шаблон без проверки его разметки и имён полей. Предложение не согласовано; код не менялся.

## Воспроизведение и доказательства

В Node исполнены исходная registerSheets с перехваченными регистрационными API и общий лист с настоящим HandlebarsApplicationMixin 14.367. Единственная подходящая системная регистрация для note — WitcherItemSheet; _configureRenderOptions выдал parts=[], _renderHTML вернул {}. Поиск note-sheet.hbs по module/templates не нашёл вызывающего кода.

Ожидаемое поведение и его основание указаны в разделе «Почему это проблема»; наблюдение не заменяет подтверждения пользователем.

**Пределы проверки:** Application/DocumentSheet и документ Item подменены; окно, выбор листа пользовательскими настройками, внешние модули и запись БД не проверялись.
