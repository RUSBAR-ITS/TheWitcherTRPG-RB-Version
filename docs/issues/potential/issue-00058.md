## Общее описание проблемы

WitcherItemSheet._onDropDocument направляет Actor, Item и Folder в _onDropActor/_onDropItem/_onDropFolder. В ядре ItemSheetV2 и общей системе этих трёх методов нет; _onDropItem определён только у шести специализированных листов.

## На что влияет в системе

Drop Actor/Folder в листы, наследующие WitcherItemSheet, и Drop Item в наследники без собственного _onDropItem завершаются TypeError. Перенос ActiveEffect использует существующий обработчик ядра.

## Почему это проблема

Неподдерживаемый документ должен получить определённый результат маршрутизации. Текущий код обещает ветви, для которых нет определения метода; ошибка подтверждена непосредственным вызовом.

## Где конкретно локализована в коде

| Файл | Локализация |

| [module/item/sheets/WitcherWeaponSheet.js](../../../module/item/sheets/WitcherWeaponSheet.js) | Один из шести собственных _onDropItem:52. |
| [module/item/sheets/WitcherArmorSheet.js](../../../module/item/sheets/WitcherArmorSheet.js) | _onDropItem:50; остальные определения — Container/Diagram/Ritual/CriticalWound. |

## Предложение по изменению

Согласовать поддерживаемые типы Drop и поведение неподдерживаемых. Затем связать маршруты с существующими обработчиками или явно завершать их без вызова отсутствующего метода. Предложение не согласовано; код не менялся.

## Воспроизведение и доказательства

Исполнены исходные WitcherItemSheet._onDrop/_onDropDocument и настоящий ItemSheetV2. Получены «this._onDropActor is not a function», «this._onDropItem is not a function», «this._onDropFolder is not a function». Other вернул null, isEditable=false — undefined. У ActiveEffect проверены успешный вызов создания, отказ для того же родителя и isOwner=false.

Ожидаемое поведение и его основание указаны в разделе «Почему это проблема»; наблюдение не заменяет подтверждения пользователем.

**Пределы проверки:** Данные drop и fromDropData подменены; не выполнялось настоящее перетаскивание в браузере или создание документов. Определения шести наследников найдены статически, их полные сценарии остаются своим порциям.
