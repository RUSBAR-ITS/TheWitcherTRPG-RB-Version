## Общее описание проблемы

associatedDiagramMixin._onDropDiagram определяет область сброса через event.target.offsetParent.dataset.type. При offsetParent=null чтение dataset выбрасывает исключение. WitcherWeaponSheet._onDropItem вызывает этот async-метод без await/return.

## На что влияет в системе

При таком DOM-контексте сброс рецепта не обновляет ссылку, а ошибка не входит в Promise внешнего _onDropItem. Какие реальные цели сброса имеют null offsetParent в клиенте, ещё нужно проверить.

## Почему это проблема

offsetParent описывает контекст позиционирования, а не гарантированного предка области associatedDiagram. Обработчик не проверяет его наличие и не распространяет завершение вложенного асинхронного вызова.

## Предложение по изменению

После согласования определить область сброса по подходящему DOM-предку с проверкой результата и связать Promise вложенного обработчика с внешним. До выбора изменения воспроизвести реальные цели сброса в браузере. Исправление не согласовано и не выполнялось.

## Воспроизведение и доказательства

Исходный _onDropItem вызван с допустимым рецептом и event.target.offsetParent=null. В изолированном Node перехвачен unhandledRejection с текстом «Cannot read properties of null (reading 'dataset')». Контроль с offsetParent.dataset.type='associatedDiagram' сохранил UUID weapon-рецепта; armor-рецепт дал уведомление и не вызвал update.

Основание ожидаемого поведения указано выше; вывод не заменяет подтверждения пользователем. Окружение, подмены API и контрольные сценарии — [журнал сверок](../../analytics/code-audit/review-log.md#task-0003013).

**Пределы проверки:** Событие и DOM представлены фасадом. Конкретная браузерная геометрия, частота проявления и полный DragDrop не проверены; проблема остаётся potential.
