## Общее описание проблемы

createTokenEmanation может вернуть void, если создание предотвращено. fromItem собирает результаты Promise.all, затем без проверки присваивает каждому region.item и actorSheet.

## На что влияет в системе

Путь эманации при отказе создания одного из регионов; дальнейшая настройка остальных результатов.

## Почему это проблема

Разрешённый контрактом API пустой результат становится TypeError. Общая цепочка скрывает отказ; созданные ранее результаты не получают гарантированной дальнейшей обработки.
