## Общее описание проблемы

В tags.hbs и текущем inventory weapons тег accuracy выводится только при gt(accuracy,0), с литералом '+'. Отрицательное значение, разрешённое WeaponData, не отображается.

## На что влияет в системе

Описание оружия в чате и раскрытая строка инвентаря не показывают штраф точности; weaponAttack при этом вычитает его из формулы.

## Почему это проблема

Нулевой модификатор и ненулевой штраф визуально не различаются. weaponAttack содержит отдельную рабочую ветвь accuracy<0. Намерение автора скрывать штраф не установлено; прежнее слово «намеренно» в карточке инвентаря заменяется описанием условия.

## Предложение по изменению

Согласовать показ любого ненулевого модификатора со знаком в обоих представлениях; сохранить 0 по выбранному правилу интерфейса. Не изменять формулу атаки.

## Воспроизведение и доказательства

Группа 07: реальные HBS для accuracy -2/0/+2 дали соответственно 0/0/1 тег точности; +2 содержит '+2'. Группа 16 проверила заполненную WeaponData. Ветви реальной формулы подтверждены чтением weaponAttack, повторный бросок не выполнялся.

Проверена потеря сведений при рендере, не изменение игрового результата. Показывать/скрывать 0 — отдельное решение пользователя.
