# Потенциальные проблемы

В этом каталоге находятся найденные, но ещё не подтверждённые пользователем проблемы. Агент создаёт отдельную карточку только после согласования регистрации.

Даже воспроизведённая агентом проблема остаётся здесь до подтверждения пользователя. После подтверждения проблемы и необходимости её исправления карточка перемещается в `open` с сохранением имени и ID. Закрытие без исправления также требует подтверждения пользователя и записанной причины.

Список карточек ведётся в [общем реестре](../README.md). Порядок работы — в [правилах](../../rules/issues.md), состав документа — в [шаблоне](../templates/issue.md).
