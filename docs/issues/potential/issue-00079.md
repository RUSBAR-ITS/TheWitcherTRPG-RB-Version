## Общее описание проблемы

WeaponData.createDefenseOption выбирает единственный skills[0] цепочкой nullish coalescing: meleeAttackSkill, rangedAttackSkill, spellAttackSkill, itemUseAttackSkill. Пустая строка не считается отсутствием и блокирует переход к заполненному следующему навыку.

## На что влияет в системе

Для оружия с meleeAttackSkill='' и rangedAttackSkill='archery' применимая защита получает skills=['']. Дополнительно начальное spellAttackSkill='spellcasting' оказывается раньше настроенного itemUseAttackSkill, независимо от attackOptions.

## Почему это проблема

Полученный вариант защиты может содержать пустой навык при наличии заполненного. Какой именно навык следует выбирать для каждого оружия, требуется согласовать по назначению вариантов; текущий fallback не проверяет пригодность значения.
