## Общее описание проблемы

WitcherActor.applyStatus сравнивает строки statusEffectImmunities с statusEffectId, но переменная с таким именем в методе не определена. При непустом массиве callback find выполняется и выбрасывает ReferenceError. Конкретный ID иммунитета при этом не важен.

## На что влияет в системе

Применение статусов через WitcherActor.applyStatus, включая статусы надетой брони при prepareDerivedData. Первый toggleStatusEffect уже вызван к моменту исключения; последующие элементы forEach не обрабатываются. Ошибка отклоняет Promise applyStatus; вызывающий prepareDerivedData этот Promise не ожидает. Фактическое сохранение статуса и сообщение браузера не проверялись.

## Почему это проблема

Проверка настроенного иммунитета должна использовать определённый ID обрабатываемого эффекта. Непустая допустимая моделью коллекция сама по себе не должна аварийно прерывать обработчик. Это отличается от applyStatusEffectToActor в отдельном scripts-файле, где statusEffectId является параметром.

## Предложение по изменению

После согласования исправления согласовать обработчик со структурой effect.statusEffect, включая отложенный toggle, и определить ожидаемый порядок применения/снятия статуса при иммунитете. Проверить пустой, совпадающий и несовпадающий иммунитеты, несколько эффектов и обработку Promise. Изменение метода не выполнено.

## Воспроизведение и доказательства

В Node 24.16.0 подключены настоящие DataModel/TypeDataModel/fields и primitives Foundry 14.367.0; создана реальная MonsterData с каждым из массивов [], ['bleeding'], ['unrelated']. Из witcherActor.js без изменения тела извлечён async applyStatus; this содержит модель, пустой Set статусов и toggleStatusEffect, который только записывает ID в массив. Передан [{statusEffect:'bleeding'}]. При [] получен один вызов toggle и успешный Promise; в обоих непустых случаях — один вызов toggle и ReferenceError: statusEffectId is not defined. setTimeout подменён контролем недостижимости и не был вызван.

Сценарий и результаты — [сверка TASK-0003.006](../../analytics/code-audit/review-log.md#task-0003006).

Пределы: Исполнен исходный метод, а не весь Actor. Toggle не менял игровой документ; состояние эффекта после реального сетевого update, полный prepareDerivedData и внешний statuscounter не проверены.
