# The Witcher TRPG — RB-Version

Это **актуальный README проекта**, форка системы The Witcher TRPG для Foundry VTT. Корневой README репозитория ведёт сюда.

## Репозиторий

- Основная ветка — **`rusbar-main`**.
- Ветка **`original`** сохраняет исходную версию для сравнения и восстановления.
- Каталог на сервере — `/var/lib/foundryvtt/Data/systems/TheWitcherTRPG-RB-Version`.

Проверенные сведения о текущем checkout и наблюдение о регистрации системы в Foundry находятся в [аналитике состояния репозитория](analytics/repository-baseline.md).

## Порядок работы

До любых изменений и принятия новых решений агент сообщает конкретное предложение и получает согласие пользователя. Выполняется только согласованный перечень; дополнения к нему также согласовываются заранее.

Правами, владельцами и группами файлов занимается пользователь. Агент сохраняет метаданные доступа существующих файлов и сообщает об ошибках доступа.

В [реестре задач](tasks/README.md) оформлены пять этапов исследования. TASK-0003 завершена: [615 карточек](analytics/code-audit/registry.md), en/ru и 226 JSON семи компедиумов. Всего 329 potential issues. [TASK-0004](tasks/task-0004-cross-checks.md) выполняется: .001–.017 done; [RollTable и их потребители](analytics/code-audit/review-log.md#task-0004017) добавили сверку 128 файлов и пяти issues. В [матрицах](analytics/code-audit/cross-check-0002.md) сопоставлены 615/615 файлов и 329/329 issues. Следующая — [TASK-0004.018](tasks/task-0004.018.md), итоговая сверка; .018 planned, TASK-0005 draft. Проверяется техническое устройство движка и экспортов; packs/, другие языки и соответствие рулбукам исключены. Исходники, игровые данные и права не изменены.

Выполненная после .040 [промежуточная сверка №1](analytics/code-audit/cross-check-0001.md) охватывает исторический массив 310 карточек и 258 issues. Её протокол и последующие порции служат входными материалами для TASK-0004; [новые матрицы](analytics/code-audit/cross-check-0002.md) отделяют этот учёт от старых доказательств.

Обязательная точка входа для агента — [AGENTS.md](../AGENTS.md).
