# The Witcher TRPG — RB-Version

Это **актуальный README проекта**, форка системы The Witcher TRPG для Foundry VTT. Корневой README репозитория ведёт сюда.

## Репозиторий

- Основная ветка — **`rusbar-main`**.
- Ветка **`original`** сохраняет исходную версию для сравнения и восстановления.
- Каталог на сервере — `/var/lib/foundryvtt/Data/systems/TheWitcherTRPG-RB-Version`.

Проверенные сведения о текущем checkout и наблюдение о регистрации системы в Foundry находятся в [аналитике состояния репозитория](analytics/repository-baseline.md).

## Порядок работы

До любых изменений и принятия новых решений агент сообщает конкретное предложение и получает согласие пользователя. Выполняется только согласованный перечень; дополнения к нему также согласовываются заранее.

Правами, владельцами и группами файлов занимается пользователь. Агент сохраняет метаданные доступа существующих файлов и сообщает об ошибках доступа.

В [реестре задач](tasks/README.md) оформлены пять этапов исследования. TASK-0001, TASK-0002 и TASK-0003.001–TASK-0003.047 выполнены. Подготовлена [351 карточка](analytics/code-audit/files/README.md) из 621; не разобраны 270 файлов. Последняя порция — три фабрики полей и семь CSS: [15 групп локальных проверок и сверка связей](analytics/code-audit/review-log.md#task-0003047), уточнения двух прежних issues, новых нет. В [пятой серии](tasks/task-0003-remaining-files.md#пятая-серия-task-0003041task-0003050) проверен 41 файл, 36 в очереди; ещё 234 требуют планирования. Следующая — TASK-0003.048. TASK-0003 остаётся в работе, TASK-0004/TASK-0005 — заготовками; общая сверка .045 сохраняется как вспомогательный материал для TASK-0004. Журнал архитектурных решений пока не содержит записей.

Выполнена [общая промежуточная сверка](analytics/code-audit/cross-check-0001.md) всего накопленного массива: 310 карточек и 258 issues. Протокол содержит результаты проверок, уточнения описаний и связи между проблемами; он служит вспомогательным материалом для TASK-0004, которая остаётся заготовкой.

Обязательная точка входа для агента — [AGENTS.md](../AGENTS.md).
