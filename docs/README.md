# The Witcher TRPG — RB-Version

## Репозиторий

- Основная ветка — **`rusbar-main`**.
- Ветка **`original`** сохраняет исходную версию для сравнения и восстановления.
- Каталог на сервере — `/var/lib/foundryvtt/Data/systems/TheWitcherTRPG-RB-Version`.

Проверенные сведения о текущем checkout и наблюдение о регистрации системы в Foundry находятся в [аналитике состояния репозитория](analytics/repository-baseline.md).

## Порядок работы

До любых изменений и принятия новых решений агент сообщает конкретное предложение и получает согласие пользователя. Выполняется только согласованный перечень; дополнения к нему также согласовываются заранее.

Правами, владельцами и группами файлов занимается пользователь. Агент сохраняет метаданные доступа существующих файлов и сообщает об ошибках доступа.

В [реестре задач](tasks/README.md) оформлены пять этапов исследования. TASK-0001–TASK-0004 завершены: [615 карточек](analytics/code-audit/registry.md), en/ru и 226 JSON семи компедиумов; 329 potential issues. [Итог сквозной сверки](analytics/code-audit/cross-check-0002.md#результаты-task-0004018) связывает предметные результаты, 14 межблочных цепочек, 168 отношений issues и адресацию всех 126 вопросов. Десять границ дальнейшей проверки описаны явно. [TASK-0005](tasks/task-0005-final-coverage.md#решение-об-отмене) отменена пользователем: дублирует уже выполненную работу, включая TASK-0004.018. Исследовано техническое устройство движка и экспортов; packs/, другие языки и соответствие рулбукам исключены. Исходники, игровые данные и права сохранены.

Выполняется [TASK-0006](tasks/task-0006-system-index.md) — справочник-граф текущей системы. .001–.018 завершены; [броня, сопротивления и износ .018](analytics/system-index/coverage-018.md) добавлены в справочник. Сейчас он содержит 4330 сущностей, 10834 связи и 268 процессов (923 шага, 1645 переходов). Определения есть в 235/615 файлах: два словаря complete по строковым ключам, 233 файла partial; роли 119 основных/116 смежных, 380 без определений. [Очередь и остаток](analytics/system-index/expansion-plan.md#second-wave) актуальны; следующая — [TASK-0006.019](tasks/task-0006.019.md), применение урона, щит и изменение ресурсов.

Выполненная после .040 [промежуточная сверка №1](analytics/code-audit/cross-check-0001.md) охватывает исторический массив 310 карточек и 258 issues. Её протокол и последующие порции служат входными материалами для TASK-0004; [новые матрицы](analytics/code-audit/cross-check-0002.md) отделяют этот учёт от старых доказательств.

Обязательная точка входа для агента — [AGENTS.md](../AGENTS.md).
