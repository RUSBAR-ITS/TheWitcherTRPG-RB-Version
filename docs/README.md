# The Witcher TRPG — RB-Version

Это **актуальный README проекта**, форка системы The Witcher TRPG для Foundry VTT. Корневой README репозитория ведёт сюда.

## Репозиторий

- Основная ветка — **`rusbar-main`**.
- Ветка **`original`** сохраняет исходную версию для сравнения и восстановления.
- Каталог на сервере — `/var/lib/foundryvtt/Data/systems/TheWitcherTRPG-RB-Version`.

Проверенные сведения о текущем checkout и наблюдение о регистрации системы в Foundry находятся в [аналитике состояния репозитория](analytics/repository-baseline.md).

## Порядок работы

До любых изменений и принятия новых решений агент сообщает конкретное предложение и получает согласие пользователя. Выполняется только согласованный перечень; дополнения к нему также согласовываются заранее.

Правами, владельцами и группами файлов занимается пользователь. Агент сохраняет метаданные доступа существующих файлов и сообщает об ошибках доступа.

В [реестре задач](tasks/README.md) оформлены пять этапов исследования. Пофайловой TASK-0003 завершён: [615 карточек из 615 файлов](analytics/code-audit/registry.md), включая en/ru и все 226 JSON семи компедиумов. [Итог .061](analytics/code-audit/review-log.md#task-0003061) содержит проверки и их ограничения; в реестре 329 potential issues. Следующий этап — [TASK-0004](tasks/task-0004-cross-checks.md), детализированный в 18 подзадач со статусом planned. Первая — [исходный срез и матрицы](tasks/task-0004.001.md); предметная сверка ещё не начата. TASK-0005 остаётся draft. Проверяется техническое устройство движка и экспортов; packs/, другие языки и соответствие рулбукам исключены. Исходники и игровые данные не изменены, журнал архитектурных решений пока пуст.

Выполненная после .040 [промежуточная сверка №1](analytics/code-audit/cross-check-0001.md) охватывает исторический массив 310 карточек и 258 issues. Её протокол и последующие порции служат входными материалами для теперь детализированной TASK-0004; новая сквозная сверка получит отдельные матрицы при выполнении .001.

Обязательная точка входа для агента — [AGENTS.md](../AGENTS.md).
