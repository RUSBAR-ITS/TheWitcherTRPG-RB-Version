## Порядок работы

Применяются [общие требования расширения](task-0006-system-index.md#общие-требования-к-расширению-006011), формат v1 и существующие постоянные ID.

1. Сопоставить documentTypes с назначениями registerDataModels и registerSheets: объявленность, регистрация и пригодность для создания — разные факты. Учесть поздние уточнения R002-01/02.
2. Записать регистрацию init/ready/updateCombat отдельно от исполнения callback, а вызов registerHooks до init — как самостоятельный вход.
3. Разделить определение settings и его чтения. Для criticalWoundsPack показать choices → чтение setting → game.packs.get → ожидание getIndex; отсутствие пакета отметить барьером без вымышленного продолжения.
4. Добавить короткие процессы настройки реестров и ready до/после getIndex, явно обозначая внешние/смежные вызовы и ожидание. Не превращать imports в процесс.
5. Перекрёстно проверить прямые/обратные записи по ключам type, sheet и setting, включая альтернативные регистрации и выбранные условия.
