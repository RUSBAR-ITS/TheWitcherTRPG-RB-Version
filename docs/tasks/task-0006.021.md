## Порядок работы

1. Связать crit/location/criticalLevel с настройкой pack, готовностью индекса, фильтром treatment/lesserEffect и fromUuid; пустой/множественный набор не заменять идеальным выбором.
2. Проследить addItem и повтор name/type по текущему .013; не переносить в справочник желаемую политику повторных травм из старых обсуждений.
3. Развести ручное создание, редактирование дней, treat/followUp, heal и автоматическое завершение; зафиксировать create/update/delete, await и сохранение эффектов как отношения документов.
4. Адресовать два calculateHealingTime у разных владельцев, BODY.max, daysHealed, sterilized и deadly; вызов при отдыхе соединить с .022.
5. Экспорт критических травм использовать только как техническое доказательство существующего UUID/Item/ActiveEffect при необходимости. Объяснить границу pack index ↔ экспорт ↔ действующий документ; не индексировать все 98 файлов здесь.
