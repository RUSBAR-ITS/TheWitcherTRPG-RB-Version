## Ведение задач

Задачи формируются с пользователем. Наблюдения в аналитике не становятся задачами автоматически. После создания ID и путь документа сохраняются при изменении статуса; ID не переиспользуются.

Для подзадач TASK-0003 по указанию пользователя применяется нумерация `TASK-0003.001`, `TASK-0003.002` и далее; файлы — `task-0003.001.md`, `task-0003.002.md`. Это номера внутри родительской задачи, они не меняют ID общих этапов.

Для оформления используется [общий шаблон](templates/task.md). Сам шаблон не является задачей.

Порядок согласования и ведения документов описан в [правилах документации](../rules/documentation.md).
