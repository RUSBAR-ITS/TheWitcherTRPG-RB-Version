# Задачи и технические задания

**Задачи пока не сформированы. Реестр пуст.**

Задачи будут формироваться с пользователем и добавляться после согласования. Наблюдения в аналитике не становятся задачами автоматически; приоритеты работ пока не назначены.

Первая задача получит ID `TASK-0001`. После создания ID и путь документа сохраняются при изменении статуса.

Для оформления используется [общий шаблон](templates/task.md). Сам шаблон не является задачей.

Порядок согласования и ведения документов описан в [правилах документации](../rules/documentation.md).
