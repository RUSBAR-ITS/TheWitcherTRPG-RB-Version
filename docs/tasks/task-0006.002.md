## Проблема и результат

Согласованное представление требуется превратить в работающий инструмент: читать записи, находить сущность, раскрывать её связи и сообщать о неполноте данных. Создать минимальный локальный поиск и валидатор с небольшим проверенным набором из трёх файлов .001.

Ожидаемый результат — воспроизводимый запуск из репозитория по документированной команде. Точные пути и язык определяются .001. Автоматический семантический разбор всего JavaScript не является обязательной частью первого инструмента.

## Требования и порядок работы

1. Проверить согласованный контракт .001 и зафиксировать перечень создаваемых файлов. Подготовить загрузку, проверку схемы и ссылок без импорта или исполнения игрового кода.
2. Использовать начальные записи из примеров .001; подтвердить их адреса и версии. Проверить различение value/label у stat() и Skill. activeEffectModifiers в этой выборке определено только у Skill; вложения модели не создавать как новые определения этого поля.
3. Реализовать поиск по ID, точному символу/пути и терминам; неоднозначный запрос возвращает различимые варианты. Чувствительность к регистру и работа с русским текстом документируются.
4. Реализовать входящий/исходящий обход, фильтр типа связи, чтение/запись поля, обращение к процессу/подробностям. Интерфейс IQ-07 может возвращать «процесс ещё не индексирован», пока записи процессов не заполнены; это не считается содержательным покрытием запроса.
5. Ограничивать глубину/объём вывода, отмечать усечение и давать способ продолжить. Цикл не вызывает бесконечный обход; запрос не меняет индекс.
6. Валидировать ID, типы, концы связей, владельцев, шаги/переходы, адреса и сведения о версии. Разрешённая внешняя граница отличима от повреждённой внутренней ссылки.
7. Добавить необходимые проверки инструмента, краткую инструкцию запуска и несколько примеров вывода. Сопоставить ожидаемые реальные записи с исходниками, а не вычислять ожидаемый ответ той же функцией поиска.

## Проверочные случаи

| Случай | Ожидаемое свойство |
| --- | --- |
| Точный ID/символ/путь | Возвращается адресуемая запись с версией и подробностями |
| value / label | Одноимённые поля stat() и Skill различаются по владельцу |
| activeEffectModifiers | В начальных трёх файлах одно определение у Skill; 13 вложений не размножают его |
| Обратный поиск | Использует ту же связь и место обращения, что прямой |
| Пустой результат / неохваченный участок / динамическая цель | Три состояния явно различимы |
| Цикл и предел обхода | Завершение, отметка усечения и возможность раскрытия |
| Дублированный ID, потерянный конец связи, неверный переход | Валидатор сообщает конкретную запись и причину |
| Поиск и проверка | Исходники, индекс, игровые документы и права не меняются |

Ошибочные записи допускаются только как отдельные тестовые входы инструмента, не как сведения о реальной системе.
