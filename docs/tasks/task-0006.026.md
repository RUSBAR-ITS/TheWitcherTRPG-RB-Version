1. Связать поля моделей и формы с общими редакторами эффектов/расходования, переиспользуя их ID.
2. Проследить выбор улучшения, заполнение enhancementItemIds, изменения applied/name/quantity и создание остатка пачки; проверить возврат из prompt и порядок записей.
