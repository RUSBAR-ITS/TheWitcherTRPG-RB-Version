## Порядок работы

1. Проследить builtin levelUpSkill от UI key через карту/цену до value, improvementPoints и magicImprovementPoints; проверить scopes локальных переменных и отсутствие/наличие guard по балансу.
2. Связать Log.addIpReward и последующий Actor.update; различить изменение массива, несколько запросов update, порядок их завершения и сообщения.
3. Добавить ручные IP controls, manual reward/spending и IP-ветку rewards API. Общая инфраструктура выбора Actor допускается как сосед; валютный расчёт не расширять.
4. Найти фактических readers/writers skillTraining и уровней профессии/Item навыков. Отсутствие автоматического обучения в обработанной области обозначать с пределом охвата, не достраивать механизм.
