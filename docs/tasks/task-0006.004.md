## Результат

Добавить компактные записи существующих процессов на сущностях и связях пилота. По запросу о методе или поле инструмент показывает процессы, конкретные шаги, условия и ссылки на подробный аудит. Повторно переписывать полные объяснения из карточек не требуется.

## Процессы и границы

| Процесс | Что должно быть доступно в справочнике |
| --- | --- |
| Подготовка Actor и расчёт характеристик | Вход жизненного цикла, порядок системных расчётов и фаз эффектов, исходные/подготовленные значения, результаты и границы ядра |
| Применение ActiveEffect к данным Actor | Условия активности и применимости, выбранные changes, фаза, цель поля и операция; динамическое разрешение цели явно обозначено |
| Получение значения навыка и модификаторов | Определения/владельцы полей, вычисляемое значение, отличия читателей в подготовке и в броске |
| Вход броска навыка → rollSkillCheck → extendedRoll | Обработчик/прямой вызов, чтение характеристики/навыка, модификаторы, ожидание ввода, оценка Roll, ветви результата/сообщения и возвращаемое значение |

Первые два процесса связаны между собой, но не должны дублировать записи шагов без указания их роли. Вход интерфейса начинается с проверенного обработчика skillListener; полнота регистрации всех листов и шаблонов вне пилота не подразумевается. Внешние методы Roll/Actor/ActiveEffect и доставка сообщения обозначаются по имеющимся доказательствам.

## Порядок работы

1. Сопоставить существующие процессы R003/R004/R005 и итоговую цепочку R018-02 с актуальными методами; выбрать устойчивые ID процессов и шагов по контракту .001.
2. Связать шаги с сущностями, чтением/записью и вызовами из .003. Добавить ветви, ранние выходы, повторное участие функций и порядок ожидания.
3. Сохранить разницу между истинной последовательностью и диагностическим обходом; статическое чтение и прежнее исполнение имеют свои доказательства.
4. Заполнить поиск участия сущности в процессе и раскрытие соседних шагов. Несуществующий/ещё не охваченный процесс должен возвращать точное состояние.
5. Проверить все IQ-01–IQ-08 на пилоте; подробные описания открываются по ссылкам, а не копируются целиком в выдачу.

## Файлы и проверки

Дополняются записи процессов, связанные сущности/отношения, покрытие и примеры поиска; точные пути берутся из .001. Основные исходники — тот же [пилот из 23 файлов](task-0006.003.md#основные-исходники), без нового пофайлового счётчика.

Проверить каждую дугу процесса по месту перехода в исходнике. Отдельно сопоставить приоритет/фазу эффекта, чтение подготовленного поля, ожидаемый вызов и ветку extendedRoll с showResult/threshold. Проверки записи процесса не требуют бросков в живом мире.
