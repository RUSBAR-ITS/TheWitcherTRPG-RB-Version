## Порядок разбора

1. Проследить подключение witcher-styles.css из system.json, все @import и url; сопоставить полный набор 36 CSS с предыдущими порциями и исключёнными ресурсами.
2. Полностью разобрать собственные правила входного CSS, system-styles.css и dialog.css; найти шаблоны/классы-потребители, области действия и пересечения каскада.
3. Сопоставить package.json с обоими utils: точки запуска, рабочий каталог, fs/path, compilePack/extractPack и зависимость CLI. Отделить объявленный диапазон версии от фактически доступной библиотеки.
4. Разобрать build.json: список includes, наличие путей и реальный потребитель. Отсутствующий ресурс и намеренно исключённый из исследования файл различать; не приписывать npm-командам неустановленное использование этого JSON.
5. Для compile/extract описать последовательность чтения/записи/удаления, имена пакетов, структуру входов/выходов, исключения и очистку полей metadata. Сопоставить с system.json и каталогами без изменения файлов.
6. Провести итоговую сверку всех 77 файлов .041–.050 с прежними 310 карточками: определения/потребители, CSS-подключения, схемы, события, источники данных и issues. Проверить остаток 234 файлов для последующего планирования.
