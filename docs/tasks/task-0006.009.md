## Порядок работы

Применяются [общие требования расширения](task-0006-system-index.md#общие-требования-к-расширению-006011), формат v1 и существующие постоянные ID.

2. Проследить producer контекста: system.skills, группировка Item-навыков, skillMap, атрибуты и hash аргументы partial. Не выводить присутствие поля из похожего имени.
3. Связать data-action/data-skill/data-item-id с конкретным callback и аргументом rollSkillCheck/rollCustomSkillCheck. Различать обработчик встроенной строки и старый #custom-rollable.
4. Отдельно описать форму SkillItemSheet → input.name → внешний submit и поле модели. Не приравнивать имя документа, ID Item и ключ карты навыков.
5. Добавить процессы текущей встроенной/собственной строки, старого входа и формы Item с точными границами; присоединить их к существующим roll-процессам.
6. Сверить R004-06/07/08/10, issue-00187/00190 и поздние уточнения; сопоставить шаблон, контекст и callback с обоих концов.
