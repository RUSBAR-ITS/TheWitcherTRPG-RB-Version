## Порядок работы

1. Сопоставить createBaseDamageObject/rollDamage с входом от .015 и отдельно обозначить входы других типов Item; полную магию не включать.
2. Отразить формулу, переменный урон, проверку вероятностей эффектов, флаги и сообщение с точными местами чтения/изменения.
3. Для attack/defense/damage проследить producer → declared schema → prepared message → consumer. Поле, переданное producer, не считать автоматически сохранённым после очистки модели.
4. Связать DamageInstance с будущими этапами щита/SP/локации .018/.019 и текстовыми отчётами; одинаковые имена в runtime object и document field не объединять.
