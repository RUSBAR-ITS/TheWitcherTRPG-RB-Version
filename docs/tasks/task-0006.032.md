## Порядок работы

1. Проследить списки Actor → Item ID → useItem/castSpell и доступность действия для трёх типов; произвольный unsupported вызов сохранить как границу.
2. Разделить исходные настройки, выбор в prompt, prepared изменения и message payload. Установить навык/WILL/штрафы, focus, calcStaminaMulti, STA и соответствующие readers/writers.
3. Проследить roll/fumble/DC, формулы damage/heal/shield и duration: вычисление не равно применению, отображение кнопки не равно вызову её callback.
4. Связать создание сообщения/схему/HTML/listener с реальными получателями .017/.019/.020/.022; проверить куда идут Self/Target и создание региона, какие вызовы ожидаются.
5. Сопоставить ссылки на ритуальные компоненты с фактическими вызовами/списанием; отсутствие такого действия в проверенном коде не заполнять предполагаемой игровой логикой.
