# История изменений

Журнал содержит выполненные изменения этого репозитория. Задачи ведутся отдельно в [реестре](tasks/README.md).

## Невыпущенные изменения

### 2026-09-10 — границы пофайлового исследования

- В [TASK-0001](tasks/task-0001-code-inventory.md#согласованные-исключения) зафиксированы согласованные исключения: `docs/`, `assets/`, `.github/`, `.git/` и перечисленные служебные файлы.
- Уточнено, что исключённые файлы не получают строк реестра и отдельных карточек, но могут использоваться как справочные источники.
- С границами исследования согласованы TASK-0003 и реестр задач. В TASK-0001 добавлены перенос перечня в README исследования и проверка соблюдения исключений.
- Проверен подсчёт для исходного коммита: из 701 отслеживаемого файла исключаются 80, остаётся 621. Это проверка состава после фильтрации, а не завершение инвентаризации или пофайлового анализа.

### 2026-09-10 — задачи пофайлового исследования

- Согласовано единое место хранения результатов: `docs/analytics/code-audit` — реестр файлов, подробные карточки, шаблон и журнал сверок.
- Подробно оформлены [TASK-0001](tasks/task-0001-code-inventory.md) по инвентаризации и [TASK-0002](tasks/task-0002-system-initialization.md) по манифесту, точке входа и регистрации компонентов.
- Созданы заготовки TASK-0003–TASK-0005 для остальных порций, сквозной сверки и итоговой проверки полноты.
- Перекрёстная сверка включена в критерии первых двух задач; дальнейшая детализация общей проверки не откладывает её выполнение.
- Обновлены [реестр задач](tasks/README.md), основной README и указатель аналитики. Выполнение этапов и создание материалов исследования ещё не начаты.

### 2026-09-10 — учёт проблем

- Создан раздел `issues` с каталогами `potential`, `open`, `closed`, общим реестром и шаблоном отдельной проблемы.
- Добавлены [правила работы с проблемами](rules/issues.md): единая нумерация `issue-00001`, предварительное согласование регистрации, подтверждение пользователем открытия и закрытия.
- Разделены регистрация проблемы, её подтверждение, постановка задачи и разрешение на исправление.
- Наблюдение о регистрации системы в Foundry оформлено как [issue-00001](issues/potential/issue-00001.md) в `potential`; аналитика ссылается на карточку. Задача не создана.
- Обновлены навигация, правила ведения документации и инструкции агента.
