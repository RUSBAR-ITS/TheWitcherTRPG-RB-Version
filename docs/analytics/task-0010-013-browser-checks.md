## Обнаруженные блокировки

### F01 — Мастер настройки модификатора обрезает содержимое

Сообщённая пользователем проблема воспроизведена для окна «волшебной палочки». При 1366×768 и 1920×1080 нижняя часть формы и кнопка подтверждения выходят за доступную область. На 1920×1080 содержимое имеет clientHeight 964 и scrollHeight 1104 при overflow:hidden; нижняя граница кнопки около1164, окна —1041. Колесо не позволяет нормально добраться до кнопки. Скриншоты `wizard-1366.png`, `wizard-1920.png`, измерения `layout.json`.

Локализация: [wizardAction в WitcherActiveEffectSheet.js](../../module/activeEffect/WitcherActiveEffectSheet.js), [поля modifier-settings.hbs](../../templates/sheets/activeEffect/modifier-settings.hbs). DialogV2.prompt открывается с узкой штатной шириной без собственной прокручиваемой области; длинные подписи и подсказки делают форму выше экрана. У основного списка changes собственная прокрутка есть — это два разных контейнера интерфейса.

Функциональное сохранение через мастер удалось проверить только при специально увеличенном viewport1920×1600. Это **не** успешная проверка обычной компоновки. Предложение для согласования: ширина мастера около640px с ограничением по viewport, прокручиваемая область полей, постоянно доступные кнопки; затем адресно проверить компактность новых настроек основной строки. Глобальные стили Foundry не менять. Исправление и новый номер issue пока не согласованы.

### F02 — Нельзя создать Item-навык

[issue-00005](../issues/potential/issue-00005.md) воспроизведена в части Item.skill. Реальный createEmbeddedDocuments вернул пустой список с DataModelValidationError: `type: "skill" is not a valid type for the Item Document class`. Модель и лист зарегистрированы, но `documentTypes.Item` манифеста не содержит skill. Поэтому Б17 и часть Б07 не могут дойти до редактора/броска собственного навыка. Подмена типа или регистрация на лету не выполнялись.

Нужно отдельно согласовать декларацию поддерживаемых типов. Проверка остальных трёх типов issue-00005 сюда не включалась; весь её объём не объявляется воспроизведённым или исправленным. Статус potential сохранён.
