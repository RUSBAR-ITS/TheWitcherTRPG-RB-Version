## Быстрый запуск

Команды из корня репозитория; установка пакетов не нужна:

```bash
python3 docs/analytics/system-index/query.py find value --match exact --kind field
python3 docs/analytics/system-index/query.py show ent-000009
python3 docs/analytics/system-index/query.py field ent-000012 --access reads
python3 docs/analytics/system-index/query.py neighbors ent-000018 --direction in --relation calls
python3 docs/analytics/system-index/query.py processes ent-000016
python3 docs/analytics/system-index/query.py process proc-000002 --limit 1
python3 docs/analytics/system-index/query.py details ent-000010
python3 docs/analytics/system-index/query.py check --freshness
```

Первый запрос на проверенном срезе находит два определения: ent-000004 — stat().value в statData.js:7 и ent-000009 — Skill.value в skillData.js:6. Читатель activeEffectModifiers — getter Skill.modifiedValue. processes src-000047 возвращает not_indexed: процессы WitcherActor пока не внесены.

Каждый ответ содержит ID, адреса исходников/карточек, область и актуальность. Поиск по ID/символу/пути точный и чувствителен к регистру; aliases поддерживают русские термины, например find НАВЫК --match exact. Для программного чтения добавить --format json после команды.

По умолчанию выдаётся до 20 результатов. --offset N продолжает страницу; --depth N у neighbors раскрывает косвенные связи. Циклы завершаются, условия не исполняются. process показывает переходы к шагам вне страницы и сохраняет выходы процесса. Входящий поиск использует те же отношения, что исходящий.

## Как читать ограничения

- partial — область описана частично; пустая выдача не доказывает отсутствие связи в системе.
- not_indexed — нужный участок ещё не внесён в справочник.
- unresolved_target / external_boundary — сохранено динамическое выражение либо граница внешнего API.
- current / stale / missing — результат проверки содержимого; --no-verify явно возвращает unchecked.
- depth_limited и page.truncated различают предел графового обхода и предел страницы.

Проверка хешей выполняется при обычном запросе: исходники каталога, реестр и использованные документы. Исторические адреса при изменении источника остаются с отметкой stale. Поиск не обновляет записи автоматически. Полная check --freshness проверяет также все карточки и ссылки; отсутствие ядра отражается как непроверенная внешняя зависимость.

При запуске по абсолютному пути инструмент работает из другого каталога: манифест по умолчанию находится рядом с query.py, корень — относительно самого скрипта. --dataset PATH перед командой позволяет читать другой набор; источники этого набора всё равно адресуют корень данного репозитория. Это не переключение корня исходников.
