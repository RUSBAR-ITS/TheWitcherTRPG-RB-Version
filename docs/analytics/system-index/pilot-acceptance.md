## Объём ответа и ручное чтение

Размеры ниже измерены у текстового stdout текущего CLI, в байтах UTF-8 и строках. Это наблюдаемое сравнение выдачи, не измерение скорости модели и не оценка токенов.

| Команда после query.py | Результатов | Байт | Строк |
| --- | ---: | ---: | ---: |
| neighbors ent-000302 --direction out --limit 100 | 17 | 4621 | 58 |
| neighbors ent-000302 --direction out --relation calls | 6 | 1958 | 25 |
| details ent-000304 | 3 | 582 | 7 |
| processes ent-000012 | 2 | 966 | 10 |

Общий neighbors у метода включает чтения/записи/передачи и может давать лишний контекст для вопроса только о вызовах. Фильтр calls уменьшает эту конкретную выдачу с 17 до 6 записей. Обращения writes и computes к одному месту не являются дублем: они отвечают на разные вопросы.

При details корпус аудита не вставляется в ответ: три адреса позволяют открыть карточку, нужный раздел и issue. При этом одну и ту же пару методов с разными местами вызова справочник сохраняет намеренно.

Ручное чтение остаётся необходимым для проверки применимости после изменения кода, полного описания issue и поздних уточнений, динамических путей и реализации внешнего API. Важные ограничения пилота:

- Не все русские термины и ключи en/ru стали aliases; поиск по смысловому синониму без внесённого обозначения не обещан.
- Шаблон wizard имеет входящую renders, но его содержимое ещё не индексировано; другие HBS/CSS и UUID экспортов пока остаются в каталоге.
- Общий schema-field stat().value объединяет обращения к разным экземплярам; конкретный путь надо читать в payload/context.
- Процесс partial раскрывает выбранный вход и шаги. Полный UI → backend → сохранение в мире, внутренние шаги ядра и все caller-цепочки не предполагаются.
- details не собирает автоматически issues из всех owner/caller; важные прямые связи требуют явных refs. Это и позволило локально исправить A18 без изменения контракта.
- Семантический охват 615 файлов ещё не достигнут. Обратный поиск по внесённому графу не заменяет поиск по исходникам вне пилота.

Ускорение дальнейшей разработки не измерялось и численно не заявляется. Пригодность подтверждена точностью адресов на выборке и возможностью ограничить контекст; её пределы перечислены выше.
