## Изменение

В [WitcherProfessionConfigurationSheet.js](../../module/item/sheets/configurations/WitcherProfessionConfigurationSheet.js) имя actions.removeEffect заменено на removeEffectDamageProperties, соответствующее кнопке общего [skillPathSkillPart.hbs](../../templates/sheets/item/configuration/partials/profession/skillPathSkillPart.hbs). Метод _oRemoveEffectDamageProperties принимает второй аргумент element и получает от него ближайшую .list-item. Event.currentTarget больше не используется для поиска строки. Адрес slot/ID и return Item.update, реализованные в .008, сохранены.

Речь о строке skillAttack.damageProperties.effects (название/статус/процент), а не об удалении встроенного документа ActiveEffect. Общий родитель и другие Item-редакторы не изменены. Текущий HBS уже содержал правильное имя действия; он проверен, но менять его не потребовалось. Единственный второй изменённый runtime-файл — system.json.version:14.3.1.00067.
