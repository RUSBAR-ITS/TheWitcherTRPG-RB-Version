# Карточки файлов

Карточки создаются по [шаблону](../templates/file.md) по мере пофайлового разбора. Общий список исходников и статусы находятся в [реестре](../registry.md), правила — в [README исследования](../README.md).

Путь карточки повторяет путь исходника относительно корня системы с добавлением `.md`: например, `module/TheWitcherTRPG.js` → `files/module/TheWitcherTRPG.js.md`.

На этапе инвентаризации карточек исходных файлов ещё нет. Этот README сохраняет каталог в Git и объясняет его назначение; он не является карточкой и не входит в подсчёт описанных файлов.
