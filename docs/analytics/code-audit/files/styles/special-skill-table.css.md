## Введённые сущности и действия с ними

Header оформляется flex с рамкой, gap20px и margin-top20px. Список переносится по строкам, select теряет border. Row — flex с вертикальным центрированием. Обе кнопки получают margin5px/width15px/align-items/justify-content, но этот общий блок сам display:flex не задаёт. Remove скрыта visibility:hidden/opacity0 и становится видимой только как непосредственный ребёнок hovered .special-skill-row; правило hover специфичнее более позднего простого remove.
