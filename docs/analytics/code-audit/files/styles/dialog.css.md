## Назначение файла

Сетка из двух равных колонок для четырёх флажков диалога отдыха.

## Условия использования

Прямой импорт № 25 из witcher-styles.css. Единственное буквальное использование .dialog-grid-checkbox в module/templates — heal-rest.hbs:3. Обёртку окна предоставляет DialogV2, она не объявлена этим файлом.

## Введённые сущности и действия с ними

JavaScript-сущностей и полей модели нет. Ниже все 1 rule-узлов и 3 declarations внутри них; внешняя вложенность сохранена. Запятые в селекторе остаются на своём уровне, стрелка обозначает CSS nesting, а не новую HTML-обёртку.

| Строка | Внешняя область | Селектор | Все объявления свойств |
| --- | --- | --- | --- |
| 1 | Корень | `.dialog-grid-checkbox` | `display: grid`; `grid-template-columns: 1fr 1fr`; `margin-bottom: 1rem` |

## Основные функции и методы

JavaScript-функций нет; селекторы и каскад обрабатывает браузер.

display:grid и grid-template-columns:1fr 1fr размещают дочерние span в двух колонках; margin-bottom:1rem отделяет их от блока результата. Эти три свойства не читают checked и не вычисляют восстановление. Структуру четырёх флагов задаёт heal-rest.hbs; _onHeal открывает окно, updateHealAmount меняет итог и скрытие подсказки через класс invisible из system-styles.css. Глобальная адресация полей и накопление флагов — существующие issues обработчика, не ошибки сетки.
