## Назначение файла

Выводит один select для выбора пути изменения или группы путей; используется и мастером листа, и выбором навыка при создании эффекта.

## Условия использования

Контекст содержит selects: записи value/label/group. DialogV2 предоставляет внешнюю форму; у select задан id=path, атрибут name отсутствует. Обработчики читают button.form.elements.path.value. Шаблон состоит из трёх логических строк без завершающего перевода строки.

## Данные и изменения состояния

Сам шаблон только показывает выбор. В нём нет задания потолка, величины бонуса, типа операции или приоритета. Эти поля нельзя приписывать мастеру по виду соседней основной формы. Последствия подтверждения различаются между двумя потребителями; источником записи остаются их методы.

## Непроверенные участки и открытые вопросы
