## Назначение файла

Содержимое диалога отдыха: четыре флага восстановления, итог HP и подсказка о стерилизации травм.

## Условия использования

Загружается через renderTemplate внутри sheet/healMixin._onHeal и передаётся content немодального DialogV2. Шаблон не предзагружается как partial и не содержит своих кнопок подтверждения/отмены: их добавляет конфигурация диалога.

## Данные и изменения состояния

Изначальная надпись использует floor(REC.max/2), переданное producer. Ни одно поле не привязано через checked к dialogData, а daysHealed здесь вообще не выводится. Подсказка сообщает возможный бонус стерилизации; действительное начисление зависит от каждого CriticalWoundData.treatment/sterilized и может отсутствовать. Шаблон не пишет Actor и не вызывает heal сам.
