## Основные функции и методы

Собственных JavaScript-функций нет. Вычисления, события и запись выполняет вызывающий JS. Собственного submit/button нет: кнопка ok создаётся DialogV2.prompt. rejectClose:true задан JS, а не этим HBS. Ввод может быть составной формулой; допустимость проверяется позднее new Roll/evaluate. Пустая строка становится 0 с уведомлением в rollDamage. Заголовок самого окна запрашивает другой, отсутствующий ключ — issue-00296; заголовок внутри формы правильный.

## Проверки и доказательства

Группа 04: исходное 1d6 попало в value, callback возвратил 2+3 и Roll получил 5; отмена/невалидный ввод отклонили обработчик. Группа 32: ключ HBS найден en/ru. Вложенность формы внутри реального DialogV2 и браузерные события не воспроизводились. Все строки прочитаны. Настоящий Handlebars использует контексты исходного producer; DOM-представление разбиралось parse5 в соответствующих сценариях.
