## Назначение файла

Сообщение о разборе предмета с заголовком источника, найденными компонентами и именами неизвестных материалов.

## Условия использования

Выбирается только createDismantleMessage из dismantlingMixin через renderTemplate. В setup/handlebars не предзагружается. Контекст содержит item, foundItems и unfoundItems; полученный HTML становится content сообщения стиля OTHER.

## Данные и изменения состояния

foundItems означает успешное разрешение ссылки, а не подтверждённую запись в инвентарь. createDismantleMessage может начаться до завершения addItem/removeItem. Записи без UUID сохраняют name и показываются в неизвестных. При UUID, разрешённом в null, producer теряет name/uuid: неизвестный раздел может содержать заголовок без имени. Шаблон не может восстановить утраченную строку.

У найденных/неизвестных компонентов quantity может быть разным, но HTML не отображает его вообще. Это установленный состав сообщения, отдельное решение об обязательном выводе количества не принималось. Пустой рецепт даёт только имя исходного предмета.
