## Назначение файла

Формирует HTML сообщения о временных улучшениях выбранного оружия: название Item, подпись типа улучшения и список имён/иконок эффектов.

## Условия использования

Шаблон рендерится по пути systems/TheWitcherTRPG/templates/chat/item/appliedTemporaryItemImprovements.hbs. Контекст передаётся из единственного найденного renderTemplate в temporaryEffectMixin: item — выбранное оружие, temporaryItemImprovements — подготовленные plain-data копии эффектов. Шаблон не создаёт документы и не проверяет успешность применения.

## Данные и изменения состояния

Контекст не модифицируется. Длительность, UUID, transfer и system.changes не выводятся. `effect.statusEffect.name` запрашивается отдельно от `effect.name`; у подготовленного обычного ActiveEffect payload такого вложенного объекта нет. При компиляции с localize-подменой, возвращающей пустую строку для отсутствующего ключа, последний span оказался пустым. Это не проверка фактического ответа Foundry localize на undefined в браузере.

Ни a.apply-status, ни data-status/data-duration здесь нет; слушатель статусов чата из applyStatusEffect.js не получает из этой разметки команд. Сам факт появления сообщения не подтверждает успешную запись эффекта: вызывающий метод не ожидает weapon.createEmbeddedDocuments.
