## Назначение файла

Сообщение о поглощении входящего урона магическим щитом.

## Условия использования

Загружается по пути systems/TheWitcherTRPG/templates/chat/damage/shieldAbsorbs.hbs через renderTemplate в [module/actor/mixins/damageMixin.js](../../../../../../../module/actor/mixins/damageMixin.js) (handleShield:51–64). Сам файл не регистрирует событий и не обращается к документам.

## Основные функции и методы

Собственных JavaScript-функций нет. Вычисления, события и запись выполняет вызывающий JS. Шаблон вызывается только при локальном остатке shield>0. При точном расходе щита до 0 сообщение не создаётся, хотя урон мог быть поглощён целиком. Его текст не сообщает отдельно фактически поглощённую сумму. Выбор условия/источника числа находится в JS; HBS лишь отображает вход.

## Проверки и доказательства

Группа 08: при shield 5 и damage 3 сообщение создано; при 5 и 8 — нет. Группа 11: при незавершённом update контекст shield=5, запрос остатка 2. Группа 32 проверила существование ключей en/ru. Все строки прочитаны. Настоящий Handlebars использует контексты исходного producer; DOM-представление разбиралось parse5 в соответствующих сценариях.
