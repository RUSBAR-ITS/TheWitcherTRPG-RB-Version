## Назначение файла

Миграционная функция переноса пяти прежних полей Weapon/Spell внутрь damageProperties. Работает с переданным сырым объектом и сама не сохраняет документ.

## Условия использования

Именованный export migrateDamageProperties(source), без импортов или глобальных Foundry-зависимостей. Вызывается из статических WeaponData.migrateData и SpellData.migrateData до super.migrateData; затем вложенная DamageProperties может преобразовать список effects в объект.

## Данные и изменения состояния

true переносится, false не переносится; пустые [] и {} truthy и перезаписывают уже заполненные вложенные effects. В смешанных данных старое armorPiercing:true побеждает новое damageProperties.armorPiercing:false. Уже преобразованные данные без старых ключей сохраняются. Присвоенный список/объект effects имеет ту же ссылку, что source.effects.

Отсутствие delete в этой функции не означает бесконечное повторение старого значения в модели: в Foundry14 неизвестные верхние поля удаляются при дальнейшей очистке WeaponData. После первого true реальный updateSource({'damageProperties.armorPiercing':false}) дал false. Запись в БД и перезагрузка мира не выполнялись.

## Непроверенные участки и открытые вопросы

Миграция записей реального мира/компедиумов не запускалась. Поведение malformed primitive/null как целого source не является штатным сценарием и не тестировалось. Исправление приоритетов требует отдельно согласованного решения.
