## Назначение файла

Фабрика двух числовых модификаторов критического результата внутри damage. Разделяет поправку места критического попадания и поправку выбора его тяжести.

## Условия использования

damageData создаёт crit:SchemaField(critData()); AttackMessageData и DamageMessageData получают эти поля через damage. Отдельная схема DefenseMessageData.crit эту фабрику не использует.

## Данные и изменения состояния

Оба поля независимы; пустые значения undefined, числовые строки очищаются NumberField, ограничение1–10 здесь отсутствует. Название crit в damage означает исходные поправки, а crit в defense — готовый результат с criticalLevel/уроном/локацией; одинаковое имя не делает эти структуры взаимозаменяемыми.
