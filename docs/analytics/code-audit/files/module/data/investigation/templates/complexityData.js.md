## Назначение файла

Фабрика двух полей сложности тайны; создаёт новый набор полей для вложенного SchemaField модели MysteryActorData.

## Условия использования

Импортируется MysteryActorData. При вызове complexity() строит поля; собственного документа, регистрации типа, вычисления сложности или броска здесь нет.
