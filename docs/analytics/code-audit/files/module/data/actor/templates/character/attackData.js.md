## Назначение файла

Определяет пару label/value, используемую только для punch и kick внутри attackStats. value хранит строку формулы; файл не определяет полное действие атаки и не совпадает с одноимённой схемой атаки сообщения чата.

## Условия использования

При импорте локальная const fields получает foundry.data.fields. Default export — фабрика определения схемы; каждый вызов создаёт новые поля. Очистку, начальные значения и валидацию применяет Foundry при создании/обновлении модели. attackStats() дважды вызывает attack(label), затем CommonActorData включает весь блок в свою схему. При вызове фабрики бросок не выполняется.

## Данные и изменения состояния

Пути — system.attackStats.punch.value и system.attackStats.kick.value. В calculateAttackStats B=ceil((BODY.value−6)/2)×2; punch='1d6+'+B, kick='1d6+'+(4+B). Формулы используют B, а не итоговый attackStats.meleeBonus, в котором может быть добавка. Явных потребителей чтения этих двух значений за пределами их определения и присвоения в module/templates/packsJson не найдено. Пустой исходный value после подготовки заменяется в памяти; Actor.update этим методом не вызывается.

Схема [module/data/chatMessage/templates/attackData.js](../../../../../../../../../module/data/chatMessage/templates/attackData.js) относится к сообщениям атаки и не импортирует эту фабрику; совпадение имени файла не означает общей сущности.
