## Назначение файла

Определяет пару name/value для ручного учёта обучения и списания очков развития. CharacterData содержит четыре независимых слота skillTraining1–skillTraining4; фабрика не создаёт Skill и не повышает его уровень.

## Условия использования

При импорте локальная const fields получает foundry.data.fields. Default export — фабрика определения схемы; каждый вызов создаёт новые поля. Очистку, начальные значения и валидацию применяет Foundry при создании/обновлении модели. CharacterData импортирует skillTraining() и вызывает её четыре раза для SchemaField. В CommonActorData и MonsterData этих полей нет.

## Данные и изменения состояния

Сохранение input по system.skillTrainingN.* идёт через форму с submitOnChange в базовом WitcherActorSheet:51–54. Кнопка списания отдельно берёт строки из DOM: при value<0 оставляет строку, иначе умножает на -1 и получает число. Затем Log обновляет историю и общий баланс. Обработчик не меняет skillTrainingN.name/value, не очищает слот и не повышает system.skills; повторное нажатие снова инициирует расход. Автоматической связи name с ключом Skill в проверенных обращениях нет.

## Непроверенные участки и открытые вопросы
