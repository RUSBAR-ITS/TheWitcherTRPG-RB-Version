## Назначение файла

Общая фабрика пяти полей для характеристик, производных параметров и числовой репутации. Определяет форму данных, но не общие игровые пределы и не формулы применения бонусов.

## Условия использования

При загрузке модуля сохраняет ссылку `fields = foundry.data.fields`. Default export `stat(label, unmodifiedMax = 0)` вызывается внутри `Stats.defineSchema`, `DerivedStats.defineSchema` и `Reputation.defineSchema`. Первые две модели оборачивают результат в `SchemaField`; Reputation возвращает его как собственную схему.

## Основные функции и методы

| Функция или метод | Входы и предусловия | Результат | Основные действия | Ошибки, асинхронность и изменения состояния |
| --- | --- | --- | --- | --- |
| stat(label, unmodifiedMax = 0) | Ключ подписи, начальное исходное значение; доступный Foundry.fields | Объект пяти DataField | Создаёт четыре NumberField и один StringField | Синхронно; без арифметики, записи документов и собственных catch. |

Число `100` для токсичности задаёт вызов фабрики, а не специальная ветка внутри неё. `max` — имя игрового поля, оно не является настройкой `NumberField.max`. Фабрика не задаёт `min`, `max`, `positive` ни одному числовому полю, не ограничивает его интервалом 1–10 и не связывает `value <= max`.

В Foundry 14.367 `NumberField` по умолчанию имеет `min/max = undefined`, `nullable = true`, `integer = false`. Для трёх полей фабрика включает integer: очистка округляет дробь до ближайшего целого. `value` остаётся числом с допустимой дробной частью. Значения 0, отрицательные и выше 10 сами эти определения не запрещают. Это установленное устройство схемы, не заключение о соответствии игровым правилам.

## Данные и изменения состояния

Вызов создаёт объекты описания полей. Реальные документы и значения не изменяются. Значение `label` хранится отдельно; `unmodifiedMax.label` — метаданные того же переданного ключа. Поля `max`, `value` и `totalModifiers` не получают отдельной подписи через этот аргумент.

Область ограничений задают потребители: например, CommonActorData ограничивает основу stun диапазоном 1–10; WitcherActor добавляет модификатор уже после этого ограничения. Эти действия не находятся в фабрике.
