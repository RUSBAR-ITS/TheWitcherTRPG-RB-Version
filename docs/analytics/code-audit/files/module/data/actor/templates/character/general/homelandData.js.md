## Назначение файла

Определяет две строки родины в биографии Actor: выбранный ключ и свободный текст для варианта other. Это отдельная схема от предмета типа homeland.

## Условия использования

При импорте локальная const fields получает foundry.data.fields. Файл экспортирует фабрику определения схемы; значениями экземпляра и валидацией занимается Foundry, а не сама фабрика. generalData.js:4,13 импортирует и вызывает homeland(). В листе эти поля редактируются, когда у Actor нет предмета homeland.

## Данные и изменения состояния

Схема допускает произвольные строки, в том числе неизвестный словарю ключ; это подтверждено вводом custom в CharacterData. Условие other существует только в шаблонах. Наличие предмета homeland переключает источник отображения; проверенная подготовка контекста не копирует его значения в general.homeland и не удаляет сохранённые строки Actor.
