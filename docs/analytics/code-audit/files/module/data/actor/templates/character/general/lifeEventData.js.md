## Назначение файла

Определяет одну запись события жизни: номер десятилетия, краткий текст, подробности и флаг раскрытия карточки. Запись не является Item или самостоятельным документом.

## Условия использования

При импорте fields получает foundry.data.fields. Фабрика lifeEvent(decade) вызывается двадцать раз из lifeEventsData.js с аргументами 1–20. Ключи окружающего объекта (10–200) создаются потребителем, а не этой функцией.

## Данные и изменения состояния

Запись не содержит ID: при сохранении используется ключ родительского объекта. Поле key добавляет подготовка контекста; в схеме lifeEvent его нет. decade — самостоятельное числовое поле, не автоматически вычисляемое из ключа; значение 1.5 принято моделью. В интерфейсе показывается key, а не decade. Нажатие раскрытия формирует обновление system.general.lifeEvents.<key>.isOpened; сама фабрика не сохраняет состояние.
