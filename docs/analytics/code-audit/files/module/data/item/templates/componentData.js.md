## Назначение файла

Маленькая фабрика схемы одной строки компонента ритуала. Отличается от module/data/item/componentData.js, который определяет самостоятельный алхимический Item.

## Условия использования

Импортируется RitualData и дважды вызывается в defineSchema для основной и альтернативной ArrayField. Каждое обращение создаёт новые экземпляры полей.

## Данные и изменения состояния

В схеме только uuid/quantity, нет name, img или ID строки. Обработчики формы записывают uuid и 1 при Drop; модель потом очищает количественную строку. Фабрика не устанавливает правила расхода материалов и не запрещает повтор одного UUID.
