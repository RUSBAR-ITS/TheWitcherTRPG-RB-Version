## Назначение файла

Фабрика полей одной расовой особенности: имя и HTML-описание. Возвращает определения для SchemaField, а не экземпляр особенности, документа или эффекта.

## Условия использования

Default function perk вызывается RaceData.defineSchema четыре раза для perk1–perk4. При импорте определяется функция; каждый вызов создаёт новые DataField. Других прямых импортов/вызовов в проверенной области не найдено.

## Данные и изменения состояния

Определения становятся вложенными полями RaceData. fieldPath после подключения — system.perk1.name/description и аналогично 2–4. Фабрика не создаёт ID особенности, отдельную коллекцию, effect, modifier или ссылку на эффект. Фиксированное число слотов задаётся RaceData, а не этой функцией. HTML-текст может описывать правило, но сам по себе не исполняет его.
