## Назначение файла

Слушает изменения цен компонентов и пересчитывает сумму дополнительных расходов в DOM. Сумму передаёт callback владельца примеси.

## Условия использования

Именованный export costEditMixin. Единственный найденный потребитель — RepairSystem: добавляет методы к Repair.prototype и из render callback DialogV2 вызывает attachHtmlListeners. Обращения выполняются к глобальному document, корень окна не передаётся. От импорта DOM не меняется.

## Данные и изменения состояния

Изменяет текст только первого найденного total-price и вызывает переданный callback. additionalCost хранится в RepairData по решению потребителя, сам mixin не знает Actor/Item. data-price остаётся исходной базой; повторный пересчёт складывает с ней текущую сумму, а не с прежним innerText. Нет проверки конечности чисел или неотрицательности; допустимые деньги/округление требуют отдельного решения.

## Непроверенные участки и открытые вопросы

Файл полностью прочитан. DOM-фасад не моделирует браузерную валидацию Number-input, закрытие/перерисовку DialogV2 и достижимость нескольких модальных окон из обычного клика. Глобальная область поиска и повторная подписка установлены точно; частота их проявления в клиенте неизвестна. Не утверждается списание NaN из кошелька: потребитель только показывает цену.
