# module/actor/parameterPersistence.js

## Текущее состояние — 14.3.1.00064

2026-09-18, TASK-0010.006. **Назначение:** Сохранение ограничений после завершённого изменения воздействий.

**Методы, сущности, действия и зависимости:** parameterActor находит владельца Actor; parameterSnapshot сохраняет пределы приобретаемой базы и максимумы ресурсов. parameterCorrections обрезает базу только при снижении допуска и запас только при падении max. prepareParameterUpdate использует native clone без save, с parameterPreview, и повторяет расчёт коррекции до устойчивого результата, включая healthState. withParameterChanges — локальная граница вложенных Item/AE-операций; внутренняя замена не запускает промежуточное обрезание. В finally учитывается реально завершённое изменение даже после частичного отказа; ошибка сохраняемой коррекции сообщается/пробрасывается. PARAMETER_INTERNAL предотвращает повторную нормализацию готовой записи. Это не транзакция БД и не межклиентная блокировка. Зависимости: parameterAdvancement, parameterPreparation, derivedStatData, native clone/update/validate; потребители — Actor/Item/AE.
