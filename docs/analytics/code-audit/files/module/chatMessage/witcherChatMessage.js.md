## Назначение файла

Точка регистрации собственного класса документа сообщения. WitcherChatMessage целиком наследует поведение ChatMessage ядра; в файле нет дополнительных полей, методов, обработчиков или механики бросков.

## Условия использования

Модуль загружается после появления глобального ChatMessage. registerDataModels назначает класс CONFIG.ChatMessage.documentClass. Модель system выбирается отдельно по type; ChatMessageData — другой, обычный класс подготовки параметров.

Собственные constructor, defineSchema, prepareData и обработчики отсутствуют. Пустое тело класса не переопределяет ни одного метода ChatMessage.

## Данные и изменения состояния

Собственных данных нет. type, system, speaker, flavor, content, rolls, author, flags и права принадлежат ядру. BaseChatMessage разрешает базовый type; system заполняется зарегистрированной моделью. Наличие этого класса само по себе не создаёт кнопки: renderChatMessageHTML подключает отдельные модули.
