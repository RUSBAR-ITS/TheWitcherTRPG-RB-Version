## Назначение файла

Изменяемый объект отдельной порции урона с типом, источником и текстовыми представлениями стадий расчёта.

## Условия использования

Именованный export class DamageInstance; импорт не создаёт экземпляров. Это обычный JavaScript-класс, без Foundry DataModel, schema, регистрации документов или автоматической сериализации. Производители — applyDamage.js и Actor.damageMixin.

## Данные и изменения состояния

Экземпляры публично изменяемы, shallow spread не сохраняет методы прототипа. Ни клонирования, ни сброса между локациями здесь нет. source='WITCHER.Damage.oil' отображается буквальным ключом в квадратных скобках. Flat-экземпляр не проходит стадию SP и показывает afterSp='null'; ошибки неизвестного type проявляются в consumer.
