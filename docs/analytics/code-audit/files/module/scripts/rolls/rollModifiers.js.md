## Назначение и использование

Единый формат численного вклада в Roll. formatRollModifier требует конечное число, выдаёт явный +/−, удаляет квадратные скобки из аннотации и не пишет пустую. formatRollContributions соединяет численные вклады. Подписи не меняют арифметику. Потребители: helper.addPart и modifierMixin; новый rollContext возвращает числа отдельно от строки.
