## Пофайловое исследование

Материалы находятся в [code-audit](code-audit/README.md): [реестр файлов](code-audit/registry.md), [шаблон карточки](code-audit/templates/file.md), [журнал сверок](code-audit/review-log.md). План работы оформлен в [TASK-0001–TASK-0005](../tasks/README.md).

Реестр содержит 621 файл после исключений. TASK-0001, TASK-0002 и TASK-0003.001–TASK-0003.031 завершены: подготовлены [250 подробных карточек](code-audit/files/README.md), 371 файл ещё не разобран. Последняя порция — весь WitcherCharacterSheet, заголовок и боковая панель; [сверка](code-audit/review-log.md#task-0003031) включает 26 групп изолированных проверок, контракты моделей/бросков/шаблонов и уточнения 30 связанных карточек. Зарегистрированы шесть potential issues, дополнены десять прежних. В [четвёртой серии](../tasks/task-0003-remaining-files.md#четвёртая-серия-task-0003031task-0003040) выполнены 3 из 63 файлов, 60 в очереди; ещё 311 требуют детализации. Следующая задача — [TASK-0003.032](../tasks/task-0003.032.md). TASK-0003 продолжается, TASK-0004/TASK-0005 остаются заготовками.

Подтверждённые факты, предположения и непроверенные вопросы должны быть явно различимы. Наблюдение не означает принятого решения или автоматически созданной задачи.

Оформление задач и выбор изменений выполняются после согласования с пользователем по [правилам работы](../rules/README.md).
