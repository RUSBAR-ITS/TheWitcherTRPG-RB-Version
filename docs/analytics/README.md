## Пофайловое исследование

Материалы находятся в [code-audit](code-audit/README.md): [реестр файлов](code-audit/registry.md), [шаблон карточки](code-audit/templates/file.md), [журнал сверок](code-audit/review-log.md). План работы оформлен в [TASK-0001–TASK-0005](../tasks/README.md).

Реестр содержит 621 файл после согласованных исключений. TASK-0001, TASK-0002 и TASK-0003.001–TASK-0003.022 завершены: подготовлены [186 подробных карточек](code-audit/files/README.md), 435 файлов ещё не разобраны. Последняя порция — пять файлов областей и событий регионов; [сверка](code-audit/review-log.md#task-0003022) включает 20 групп изолированных проверок и встречные связи. В [третьей серии](../tasks/task-0003-remaining-files.md#третья-серия-task-0003021task-0003030) выполнены 18 из 79 файлов, 61 остаётся в очереди; ещё 374 требуют детализации. Следующая задача — [TASK-0003.023](../tasks/task-0003.023.md). TASK-0003 продолжается; TASK-0004 и TASK-0005 остаются заготовками.

Подтверждённые факты, предположения и непроверенные вопросы должны быть явно различимы. Наблюдение не означает принятого решения или автоматически созданной задачи.

Оформление задач и выбор изменений выполняются после согласования с пользователем по [правилам работы](../rules/README.md).
