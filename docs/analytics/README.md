## Пофайловое исследование

Материалы находятся в [code-audit](code-audit/README.md): [реестр файлов](code-audit/registry.md), [шаблон карточки](code-audit/templates/file.md), [журнал сверок](code-audit/review-log.md). План работы оформлен в [TASK-0001–TASK-0005](../tasks/README.md).

Текущий [реестр](code-audit/registry.md) содержит 615 файлов: [396 карточек](code-audit/files/README.md) подготовлены, 219 JSON ожидают разбора в .053–.061. [TASK-0003.052](../tasks/task-0003.052.md) описывает семь таблиц стиля/ценностей и связи с общим генератором. [Сверка](code-audit/review-log.md#task-0003052) фиксирует модели, броски, вывод и пределы изолированного исполнения. TASK-0003 продолжается; TASK-0004/TASK-0005 остаются draft. Другие языки кроме en/ru, содержимое packs/ и соответствие рулбукам исключены; прежние результаты сохранены.

После .040 выполнена [общая промежуточная сверка № 1](code-audit/cross-check-0001.md) всех 310 карточек и 258 issues: 14 блоков, 71 новая группа изолированных проверок, пять уточнений описаний и один выявленный дубль (00200/00029). Состав исходников и статусы issues сохранены. Материал предназначен для последующей детализации TASK-0004; задача остаётся draft.

Подтверждённые факты, предположения и непроверенные вопросы должны быть явно различимы. Наблюдение не означает принятого решения или автоматически созданной задачи.

Оформление задач и выбор изменений выполняются после согласования с пользователем по [правилам работы](../rules/README.md).
