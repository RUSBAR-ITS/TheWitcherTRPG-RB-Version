## Пофайловое исследование

Материалы находятся в [code-audit](code-audit/README.md): [реестр файлов](code-audit/registry.md), [шаблон карточки](code-audit/templates/file.md), [журнал сверок](code-audit/review-log.md). План работы оформлен в [TASK-0001–TASK-0005](../tasks/README.md).

Реестр содержит 621 файл после исключений. TASK-0001, TASK-0002 и TASK-0003.001–TASK-0003.039 завершены; подготовлены [300 карточек](code-audit/files/README.md), 321 файл ещё не разобран. Последняя порция — магия Actor, шесть файлов. [Сверка](code-audit/review-log.md#task-0003039) содержит 33 группы изолированных проверок, уточнения 34 связанных карточек и 17 прежних issues. Добавлены десять potential issues (00245–00254). [Общая сверка .031–.035](code-audit/review-log.md#task-0003035) сохранена. В [четвёртой серии](../tasks/task-0003-remaining-files.md#четвёртая-серия-task-0003031task-0003040) проверены 53 из 63 файлов, 10 в очереди; ещё 311 требуют детализации. Следующая — [TASK-0003.040](../tasks/task-0003.040.md), сообщения чата и общая сверка серии. TASK-0003 продолжается, TASK-0004/TASK-0005 остаются заготовками.

Подтверждённые факты, предположения и непроверенные вопросы должны быть явно различимы. Наблюдение не означает принятого решения или автоматически созданной задачи.

Оформление задач и выбор изменений выполняются после согласования с пользователем по [правилам работы](../rules/README.md).
