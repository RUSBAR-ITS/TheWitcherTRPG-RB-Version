## Пофайловое исследование

Материалы находятся в [code-audit](code-audit/README.md): [реестр файлов](code-audit/registry.md), [шаблон карточки](code-audit/templates/file.md), [журнал сверок](code-audit/review-log.md). План работы оформлен в [TASK-0001–TASK-0005](../tasks/README.md).

Реестр содержит 621 файл после исключений. TASK-0001, TASK-0002 и TASK-0003.001–TASK-0003.030 завершены: подготовлены [247 подробных карточек](code-audit/files/README.md), 374 файла ещё не разобраны. Последняя порция — девять файлов характеристик, модификаторов и проверок состояния; [сверка](code-audit/review-log.md#task-0003030) включает 19 новых групп изолированных проверок, повторные 22 группы .029 и итоговое сопоставление 79 файлов третьей серии с прежними 168. Уточнены 25 связанных карточек; отозвано ошибочное утверждение об отсутствии семи dotted-ключей переводов. Третья серия завершена; [четвёртая серия](../tasks/task-0003-remaining-files.md#четвёртая-серия-task-0003031task-0003040) поставлена в очередь на 63 файла, ещё 311 требуют детализации. [Проверка плана](code-audit/review-log.md#планирование-task-0003031task-0003040) подтвердила состав без изменения покрытия. Следующая задача — [TASK-0003.031](../tasks/task-0003.031.md), её выполнение не начато. TASK-0003 продолжается, TASK-0004/TASK-0005 остаются заготовками.

Подтверждённые факты, предположения и непроверенные вопросы должны быть явно различимы. Наблюдение не означает принятого решения или автоматически созданной задачи.

Оформление задач и выбор изменений выполняются после согласования с пользователем по [правилам работы](../rules/README.md).
