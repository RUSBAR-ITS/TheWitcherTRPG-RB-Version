## Пофайловое исследование

Материалы находятся в [code-audit](code-audit/README.md): [реестр файлов](code-audit/registry.md), [шаблон карточки](code-audit/templates/file.md), [журнал сверок](code-audit/review-log.md). План работы оформлен в [TASK-0001–TASK-0005](../tasks/README.md).

Реестр содержит 621 файл после согласованных исключений. TASK-0001, TASK-0002 и TASK-0003.001–TASK-0003.020 завершены: подготовлены [168 подробных карточек](code-audit/files/README.md), 453 файла ещё не разобраны. Последняя порция — 10 файлов травм, лечения и отдыха; [сверка второй серии](code-audit/review-log.md#task-0003020) охватила 96 файлов и их связи с прежними 72. Подготовлена [третья серия TASK-0003.021–TASK-0003.030](../tasks/task-0003-remaining-files.md#третья-серия-task-0003021task-0003030) на 79 файлов; ещё 374 требуют детализации. [Проверка плана](code-audit/review-log.md#планирование-task-0003021task-0003030) не увеличила покрытие. Следующая задача — [TASK-0003.021](../tasks/task-0003.021.md). TASK-0003 продолжается; TASK-0004 и TASK-0005 остаются заготовками.

Подтверждённые факты, предположения и непроверенные вопросы должны быть явно различимы. Наблюдение не означает принятого решения или автоматически созданной задачи.

Оформление задач и выбор изменений выполняются после согласования с пользователем по [правилам работы](../rules/README.md).
