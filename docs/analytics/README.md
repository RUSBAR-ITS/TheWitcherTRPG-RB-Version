## Пофайловое исследование

Материалы находятся в [code-audit](code-audit/README.md): [реестр файлов](code-audit/registry.md), [шаблон карточки](code-audit/templates/file.md), [журнал сверок](code-audit/review-log.md). План работы оформлен в [TASK-0001–TASK-0005](../tasks/README.md).

Реестр содержит 621 файл после исключений. TASK-0001, TASK-0002 и TASK-0003.001–TASK-0003.036 завершены; подготовлены [282 карточки](code-audit/files/README.md), 339 файлов ещё не разобраны. Последняя порция — обмен валюты, четыре файла. [Сверка](code-audit/review-log.md#task-0003036) содержит 21 группу изолированных проверок, уточнения 15 связанных карточек и трёх прежних issues. Добавлены пять potential issues (00227–00231); уточнён пропущенный в .035 этап очистки DialogV2.content. [Общая сверка .031–.035](code-audit/review-log.md#task-0003035) сохранена. В [четвёртой серии](../tasks/task-0003-remaining-files.md#четвёртая-серия-task-0003031task-0003040) проверены 35 из 63 файлов, 28 в очереди; ещё 311 требуют детализации. Следующая — [TASK-0003.037](../tasks/task-0003.037.md), награды. TASK-0003 продолжается, TASK-0004/TASK-0005 остаются заготовками.

Подтверждённые факты, предположения и непроверенные вопросы должны быть явно различимы. Наблюдение не означает принятого решения или автоматически созданной задачи.

Оформление задач и выбор изменений выполняются после согласования с пользователем по [правилам работы](../rules/README.md).
