# Аналитика

Раздел содержит исследования текущего репозитория. Каждое исследование указывает дату, ветку/коммит, источники и фактически выполненные проверки.

| Документ | Содержание |
| --- | --- |
| [Состояние репозитория](repository-baseline.md) | Ветки, манифест, доступные команды и наблюдение о возможном несоответствии регистрации в Foundry |

Подтверждённые факты, предположения и непроверенные вопросы должны быть явно различимы. Наблюдение не означает принятого решения или автоматически созданной задачи.

Оформление задач и выбор изменений выполняются после согласования с пользователем по [правилам работы](../rules/README.md).
