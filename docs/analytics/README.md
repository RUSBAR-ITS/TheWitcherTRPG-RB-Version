## Запланированное пофайловое исследование

Для реестра файлов, подробных карточек и журнала перекрёстных проверок согласован каталог `docs/analytics/code-audit`. План работы оформлен в [TASK-0001–TASK-0005](../tasks/README.md).

Первые две задачи описывают инвентаризацию и разбор манифеста, точки входа и регистрации компонентов. Остальные задачи оставлены заготовками для дальнейшей детализации и разбиения на подзадачи. Материалы исследования ещё предстоит создать при выполнении задач.

Подтверждённые факты, предположения и непроверенные вопросы должны быть явно различимы. Наблюдение не означает принятого решения или автоматически созданной задачи.

Оформление задач и выбор изменений выполняются после согласования с пользователем по [правилам работы](../rules/README.md).
