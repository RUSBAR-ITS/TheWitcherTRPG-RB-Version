## Пофайловое исследование

Материалы находятся в [code-audit](code-audit/README.md): [реестр файлов](code-audit/registry.md), [шаблон карточки](code-audit/templates/file.md), [журнал сверок](code-audit/review-log.md). План работы оформлен в [TASK-0001–TASK-0005](../tasks/README.md).

Реестр содержит 621 файл после исключений. TASK-0001, TASK-0002 и TASK-0003.001–TASK-0003.035 завершены; подготовлены [278 карточек](code-audit/files/README.md), 343 файла ещё не разобраны. Последняя порция — добыча/торговля и mount, шесть файлов. [Сверка](code-audit/review-log.md#task-0003035) содержит 26 групп изолированных проверок, общую сверку 31 файла .031–.035 с прежними 247, уточнения 17 связанных карточек и 12 прежних issues. Добавлены девять potential issues (00218–00226). В [четвёртой серии](../tasks/task-0003-remaining-files.md#четвёртая-серия-task-0003031task-0003040) проверен 31 из 63 файлов, 32 в очереди; ещё 311 требуют детализации. Следующая — [TASK-0003.036](../tasks/task-0003.036.md), обмен валюты. TASK-0003 продолжается, TASK-0004/TASK-0005 остаются заготовками.

Подтверждённые факты, предположения и непроверенные вопросы должны быть явно различимы. Наблюдение не означает принятого решения или автоматически созданной задачи.

Оформление задач и выбор изменений выполняются после согласования с пользователем по [правилам работы](../rules/README.md).
