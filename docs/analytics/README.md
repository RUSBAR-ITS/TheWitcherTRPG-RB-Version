## Пофайловое исследование

Материалы находятся в [code-audit](code-audit/README.md): [реестр файлов](code-audit/registry.md), [шаблон карточки](code-audit/templates/file.md), [журнал сверок](code-audit/review-log.md). План работы оформлен в [TASK-0001–TASK-0005](../tasks/README.md).

Реестр содержит 621 файл после согласованных исключений. TASK-0001, TASK-0002 и TASK-0003.001–TASK-0003.023 завершены: подготовлены [200 подробных карточек](code-audit/files/README.md), 421 файл ещё не разобран. Последняя порция — 14 файлов расследований; [сверка](code-audit/review-log.md#task-0003023) включает 17 групп изолированных проверок и встречные связи. В [третьей серии](../tasks/task-0003-remaining-files.md#третья-серия-task-0003021task-0003030) выполнены 32 из 79 файлов, 47 остаются в очереди; ещё 374 требуют детализации. Следующая задача — [TASK-0003.024](../tasks/task-0003.024.md). TASK-0003 продолжается; TASK-0004 и TASK-0005 остаются заготовками.

Подтверждённые факты, предположения и непроверенные вопросы должны быть явно различимы. Наблюдение не означает принятого решения или автоматически созданной задачи.

Оформление задач и выбор изменений выполняются после согласования с пользователем по [правилам работы](../rules/README.md).
